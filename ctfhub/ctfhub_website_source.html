# CTFHub # Web # 信息泄露 # 备份文件下载 # 网站源码

一、题目信息

  • 题目名称：网站源码
  • 题目方向：Web - 信息泄露 - 备份文件下载
  • 题目环境：动态分配的 HTTP 服务地址
  • 题目目标：寻找被放置在 Web 目录下的网站源码备份文件，并根据备份内容定位 Flag。

二、解题工具

  • 浏览器：查看题目提示和响应内容。
  • cURL：探测备份文件并下载压缩包。
  • unzip 或 tar：查看和解压网站备份文件。

三、解题思路与步骤

  1. 分析首页提示：访问题目根路径后，页面直接给出了常见的网站源码备份文件名和后缀。常见文件名包括 web、website、backup、back、www、wwwroot、temp，常见后缀包括 tar、tar.gz、zip、rar。
  2. 枚举备份文件：根据提示组合文件名和后缀，并使用 HEAD 请求检查状态码。测试到 /www.zip 时返回 200 OK，响应类型为 application/zip，说明网站源码备份文件被直接暴露在 Web 根目录下。 
    curl.exe -I "http://challenge-xxx.sandbox.ctfhub.com:10800/www.zip"
  3. 下载并解压：将备份文件下载到本地，并查看压缩包结构： 
    curl.exe -s "http://challenge-xxx.sandbox.ctfhub.com:10800/www.zip" -o www.zip
tar.exe -tf www.zip
    压缩包中包含 50x.html、index.html 和 flag_2282029806.txt。
  4. 检查 Flag 文件：读取压缩包中的 flag_2282029806.txt： 
    tar.exe -xOf www.zip flag_2282029806.txt
    本例中该文件内容为提示 where is flag ??，说明需要继续检查服务器上对应的同名文件。
  5. 访问备份中的文件路径：使用压缩包中泄露的完整文件名，直接访问服务器根目录下的同名文件： 
    curl.exe "http://challenge-xxx.sandbox.ctfhub.com:10800/flag_2282029806.txt"
    响应内容即为最终 Flag。

四、最终 Flag

ctfhub{a11fee757b37de36d3d69cd4}

五、解题总结

  • 备份文件不能放在 Web 目录：www.zip 等源码备份文件一旦被访问，就可能泄露网站结构、源代码和敏感文件。
  • 使用常见字典探测：备份文件通常具有固定的命名习惯，可以使用常见文件名与后缀组合进行目录扫描。
  • 检查备份中的全部路径：解压后不仅要查看文件内容，还要关注文件名和目录结构，尝试访问服务器上的对应路径。
  • 响应头可以辅助判断：Content-Type: application/zip 和 200 OK 能快速确认探测到的备份文件有效。
