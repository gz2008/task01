CTFHub - Misc - 流量分析 - ping也可以携带数据？

# CTFHub # Misc # 流量分析 # Wireshark # ICMP

一、题目信息

  • 题目名称：ping也可以携带数据？
  • 题目方向：Misc - 流量分析
  • 题目附件：icmp_data.pcap

二、解题工具

  • Wireshark (网络协议分析器)

三、解题思路与步骤

  1. 下载附件并导入：将附件 icmp_data.pcap 下载到本地，使用 Wireshark 打开。
  2. 过滤流量：根据题目提示，ping 命令使用的是 ICMP 协议。在顶部显示过滤器栏输入 icmp 并回车，筛选出所有 ping 数据包。
  3. 分析 Data 字段规律：选中任意一个 ping 请求包，查看底部的 Data (64 bytes) 字段。经过仔细观察发现：
    • 开头是变化的干扰数据（如 46451218）。
    • 中间存在固定的前导码 ed ac d7 41，将其作为定位标志。
    • 前导码后紧跟的一个字节是变化的（如 63、74、66 等），这才是真正隐藏的 Flag 数据。
    • 剩余部分全部是 4d（ASCII 字符 'M'），属于出题人故意添加的大量填充干扰项。
  4. 提取有效数据：按顺序遍历每一个 ping 数据包，提取 ed ac d7 41 后面的第一个字节。例如：
    • 第 7 包：63 -> 'c'
    • 第 9 包：74 -> 't'
    • 第 11 包：66 -> 'f'
    • 第 13 包：68 -> 'h'
  5. 拼接并解码：将提取出的所有有效字节按顺序拼接（如 63 74 66 68...），使用在线十六进制转 ASCII 工具进行解码，最终得到格式为 ctfhub{...} 的 Flag。

四、最终 Flag

ctfhub{c87eb99796406ac0b}

五、解题总结

这道题揭示了 ICMP 协议在流量分析中的一个重要考点：数据外带。

  • ICMP 并不安全：虽然 ping 通常用来测试连通性，但它的 Data 字段可以承载任意数据。黑客经常利用它建立隐蔽隧道来传输文件或敏感信息。
  • 善于发现规律：当数据分散在几十个数据包中时，要善于寻找包与包之间的共同点（如前导码 ed ac d7 41）和差异点（可变字节），从而准确定位真正携带信息的载荷。
  • 识别干扰项：很多 CTF 流量分析题会加入大量无意义的重复字节（如本题的 4d/'M'）作为噪声，做题时需要具备筛选和剔除噪声的能力。
