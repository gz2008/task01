CTFHub - Web - 信息泄露 - 目录遍历

# CTFHub # Web # 信息泄露 # 目录遍历 # Python

一、题目信息

  • 题目名称：目录遍历
  • 题目方向：Web - 信息泄露
  • 题目环境：动态分配的 HTTP 服务地址
  • 题目目标：遍历 flag_in_here/ 下的多级目录，定位并读取 flag.txt。

二、解题工具

  • 浏览器：查看目录索引并逐级访问目录。
  • Python 3：自动请求页面、解析目录链接并进行广度优先遍历。
  • cURL：验证目标文件并读取 Flag。

三、解题思路与步骤

  1. 访问题目入口：首页标题为“目录遍历”，页面中提供一个指向 flag_in_here/ 的按钮，点击后进入目标目录。
  2. 识别目录索引：访问 /flag_in_here/ 后，服务器返回 Apache Directory Index。当前目录包含 1/、2/、3/、4/ 四个子目录，但没有直接显示 Flag。
  3. 分析目录结构：进入任意一级目录后，下一层仍然包含多个数字目录。由于目录存在多层和多个分支，手动点击效率较低，因此使用广度优先搜索遍历全部目录。
  4. 自动化遍历目录：脚本请求每个目录页面，使用正则表达式提取其中的 href。目录链接加入队列，文件链接则下载并检查内容： 
    import re
import urllib.parse
import urllib.request

base = "http://challenge-xxx.sandbox.ctfhub.com:10800/flag_in_here/"
queue = [base]
seen = {base}

while queue:
    url = queue.pop(0)
    html = urllib.request.urlopen(url, timeout=10).read().decode("utf-8", "replace")

    for href in re.findall(r'href="([^"]+)"', html):
        if href.startswith("?"):
            continue

        next_url = urllib.parse.urljoin(url, href)
        if not next_url.startswith(base) or next_url in seen:
            continue

        seen.add(next_url)
        if href.endswith("/"):
            queue.append(next_url)
        else:
            data = urllib.request.urlopen(next_url, timeout=10).read().decode("utf-8", "replace")
            if "ctfhub{" in data:
                print(f"URL: {next_url}")
                print(data)
                raise SystemExit
  5. 定位目标文件：脚本遍历到 /flag_in_here/3/2/ 时，目录索引中出现 flag.txt，其完整路径为： 
    /flag_in_here/3/2/flag.txt
  6. 读取 Flag：通过浏览器打开目标文件，或者使用 cURL 请求完整路径： 
    curl.exe "http://challenge-xxx.sandbox.ctfhub.com:10800/flag_in_here/3/2/flag.txt"
    返回内容即为最终 Flag。

四、最终 Flag

ctfhub{b3ed95130620ae19d401c444}

五、解题总结

  • 识别目录索引：Apache Directory Index 会直接列出当前目录下的文件和子目录，是信息泄露题中常见的入口。
  • 递归遍历所有分支：目标文件嵌套在 3/2/ 目录中，只检查当前层无法发现，需要遍历完整目录树。
  • 使用脚本提高效率：面对多层、多分支目录时，可以用 Python、wget 或递归爬虫自动解析链接并检测目标文件。
  • 注意题目类型：本题是利用目录索引进行信息收集，并不是通过 ../ 利用路径穿越漏洞。
