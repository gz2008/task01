# CTFHub # Web # HTTP协议 # Cookie

一、题目信息

  • 题目名称：Cookie
  • 题目方向：Web - Web前置技能 - HTTP协议
  • 题目环境：动态分配的 HTTP 服务地址

二、解题工具

  • 浏览器开发者工具（F12）或 Burp Suite（抓包工具）

三、解题思路与步骤

  1. 分析提示：访问题目页面，显示“hello guest. only admin can get flag.”，提示当前用户是访客，只有管理员才能获取 Flag。
  2. 查看 Cookie：按 F12 打开开发者工具，切换到 Application (应用) 标签。在左侧找到 Cookies，发现服务器下发了一个名为 admin 的 Cookie，其值为 0。
  3. 修改 Cookie：双击该字段的值，将 0 修改为 1，并按回车保存。
  4. 获取 Flag：刷新页面。服务器读取到 admin=1 后，误认为当前用户是管理员，页面上直接返回了包含 Flag 的内容。

四、最终 Flag

ctfhub{请替换为你获取到的真实Flag}

五、解题总结

  • Cookie 存储在客户端：Cookie 由服务器下发，但保存在用户的浏览器中，用户可以任意修改其内容。
  • 不能信任前端数据：服务器端如果直接信任了 Cookie 中的身份标识（如 admin=0/1）而不做服务端二次校验，攻击者就可以通过修改 Cookie 来伪造身份（越权）。
  • 安全建议：开发时应使用签名（如 JWT）或服务端 Session 来存储敏感信息，并对用户输入保持“永远不要信任”的态度。
