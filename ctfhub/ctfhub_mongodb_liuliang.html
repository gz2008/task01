CTFHub - Misc - 流量分析 - MongoDB流量

# CTFHub # Misc # 流量分析 # Wireshark # MongoDB

一、题目信息

  • 题目名称：MongoDB流量
  • 题目方向：Misc - 流量分析
  • 题目附件：mongodb.pcap

二、解题工具

  • Wireshark (网络协议分析器)

三、解题思路与步骤

  1. 下载附件并导入：将附件 mongodb.pcap 下载到本地，使用 Wireshark 打开。
  2. 过滤流量：MongoDB 默认端口为 27017。在显示过滤器栏中输入 mongo 或 tcp.port == 27017 并回车。
  3. 追踪 TCP 流：选中任意数据包，右键点击 -> 选择 追踪流 (Follow) -> TCP 流 (TCP Stream)。
  4. 排查数据流：
    • 首先查看“流 1”，发现里面只包含 ismaster、listCollections、dbStats、endSessions 等数据库连接初始化和状态检查命令，并未发现业务数据与 Flag。
    • 在追踪流窗口右下角切换至“流 2”。在“流 2”的数据交互中，发现了具体的数据库操作（如 insert 或 find 等），并在数据内容中发现了 ctfhub{...} 格式的字符串。
  5. 提取 Flag：确认该字符串即为最终需要的 Flag。

四、最终 Flag

ctfhub{请替换为你找到的真实Flag}

五、解题总结

这道题考察了针对 MongoDB 数据库流量的分析能力，核心经验总结如下：

  • 协议过滤：Wireshark 中 MongoDB 的显示过滤器为 mongo，或者通过默认端口 tcp.port == 27017 过滤。
  • 多流排查思维：数据库流量包通常包含多个 TCP 流。前面的流往往只是连接握手、鉴权和元数据查询（如流1），真正的业务数据（增删改查）通常隐藏在后续的流中。切忌在第一个流中死磕。
  • 格式辨识：MongoDB 使用 BSON 格式，追踪流时可能夹杂少量乱码，但搜索 ctfhub{ 关键字依然能精准定位。
