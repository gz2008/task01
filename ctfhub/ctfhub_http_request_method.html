CTFHub - Web - Web前置技能 - HTTP协议 - 请求方式

# CTFHub # Web # HTTP协议 # 请求方式

一、题目信息

  • 题目名称：请求方式
  • 题目方向：Web - Web前置技能 - HTTP协议
  • 题目环境：动态分配的 HTTP 服务地址

二、解题工具

  • cURL（命令行工具）或 Burp Suite（抓包工具）

三、解题思路与步骤

  1. 分析提示：访问题目提供的 URL，页面提示“HTTP Method is GET Use CTF**B Method”。结合平台域名 ctfhub.com，推断出需要将 HTTP 请求方法修改为自定义的 CTFHUB。
  2. 方法一：使用 cURL 发送自定义请求
    打开终端（CMD、PowerShell 或 Git Bash），输入以下命令： 
    curl -v -X CTFHUB http://challenge-xxx.sandbox.ctfhub.com:10800/index.php
    • -v：显示详细通信过程，方便调试。
    • -X CTFHUB：指定自定义的 CTFHUB 请求方法。
  3. 方法二：使用 Burp Suite 抓包修改
    配置浏览器代理，访问题目地址。在 Burp Suite 拦截到的请求包中，将第一行修改为： 
    CTFHUB /index.php HTTP/1.1
    然后放行请求，服务器返回的响应包中即包含 Flag。

四、最终 Flag

ctfhub{请替换为你获取到的真实Flag}

五、解题总结

  • HTTP方法可自定义：HTTP 协议并未限制请求方法的具体单词，服务器端可以自定义并检查特定的方法名。
  • 区分大小写：自定义方法名通常区分大小写，本题必须使用大写 CTFHUB。
  • 浏览器限制：普通浏览器只能发送标准方法（如 GET、POST），无法直接发送自定义请求方法，因此必须借助 cURL 或 Burp Suite 等工具来完成。
