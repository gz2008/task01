# CTFHub # Web # HTTP协议 # 响应包源代码

一、题目信息

  • 题目名称：响应包源代码
  • 题目方向：Web - Web前置技能 - HTTP协议
  • 题目环境：动态分配的 HTTP 服务地址

二、解题工具

  • 浏览器（自带查看源码功能）或 cURL 命令

三、解题思路与步骤

  1. 分析提示：题目提示“HTTP响应包源代码查看”。说明 Flag 直接隐藏在服务器返回的 HTML 源码中，需要查看网页的源代码。
  2. 查看网页源码：访问题目地址后，直接按下快捷键 Ctrl + U（或右键 → 查看页面源代码）。
  3. 搜索 Flag：在源码页面按 Ctrl + F，搜索 ctfhub 或 flag，即可在注释或标签中看到最终的 Flag。

四、最终 Flag

ctfhub{请替换为你获取到的真实Flag}

五、解题总结

  • 浏览器渲染 vs 源代码：浏览器“检查元素”看到的是经过 JavaScript 动态渲染后的 DOM 树，而 Ctrl + U 看到的是服务器发回来的最原始的 HTML 文本，两者有时并不相同。
  • 隐藏信息：开发人员有时会将提示、Flag 或敏感信息写在 HTML 注释里，通过查看源代码的方式可以直接获取这些隐藏信息。
