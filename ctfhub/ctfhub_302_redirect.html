# CTFHub # Web # HTTP协议 # 302跳转

一、题目信息

  • 题目名称：302跳转
  • 题目方向：Web - Web前置技能 - HTTP协议
  • 题目环境：动态分配的 HTTP 服务地址

二、解题工具

  • cURL（命令行工具）或 Burp Suite（抓包工具）

三、解题思路与步骤

  1. 分析提示：题目名称“302跳转”，提示“HTTP临时重定向”。直接使用浏览器访问会被自动重定向，导致无法看到中间过程。我们需要查看 HTTP 响应头中的 Location 字段。
  2. 访问根目录：使用 curl -v http://challenge-xxx.sandbox.ctfhub.com:10800/ 访问根路径。发现返回状态码 200 OK，网页提示 “No Flag here!” 并包含一个指向 index.php 的链接。
  3. 请求 index.php：使用命令 curl -v http://challenge-xxx.sandbox.ctfhub.com:10800/index.php 获取真实重定向逻辑。
  4. 获取 Flag：终端输出中会显示状态码 302 Found。在响应头中找到 Location: 字段，其中包含的 URL 通常就带有 Flag，或者顺着该 URL 继续访问即可得到 Flag。

四、最终 Flag

ctfhub{请替换为你获取到的真实Flag}

五、解题总结

  • 302状态码：表示临时重定向。服务器返回 302 时，会在响应头 Location 中指定新的 URL，浏览器会自动跳转。
  • 抓包的重要性：浏览器会自动处理重定向，导致人眼看不到跳转过程中的细节。Web 安全中常用 Burp Suite 或 cURL 来阻止自动跳转，从而分析中间的 HTTP 响应头。
  • 与“请求方式”题的区别：上一题考的是“如何问”（请求方法），这道题考的是“服务器如何答”（响应状态码），两者是 HTTP 协议中对立又统一的基础知识点。
