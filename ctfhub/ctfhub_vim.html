CTFHub - Web - 信息泄露 - 备份文件下载 - vim缓存

# CTFHub # Web # 信息泄露 # 备份文件下载 # Vim

一、题目信息

  • 题目名称：vim缓存
  • 题目方向：Web - 信息泄露 - 备份文件下载
  • 题目环境：动态分配的 HTTP 服务地址
  • 题目提示：Flag 位于 index.php 源码中；开发人员异常退出 Vim 时可能遗留缓存文件。

二、漏洞原理

Vim 在编辑文件时会生成交换文件（swap file），默认文件名通常是在原文件名前加一个点，并以 .swp 结尾。例如编辑 index.php 时，会生成：

.index.php.swp

如果 Vim 异常退出，且交换文件没有被及时清理，它会一直保留在服务器目录中。Web 服务器通常将该文件作为静态文件返回，因此攻击者可以直接下载并恢复源码或从其中提取敏感内容。

三、解题工具

  • 浏览器：查看首页提示。
  • cURL：下载 Vim 交换文件。
  • strings 或 vim -r：查看或恢复交换文件内容。

四、解题步骤

  1. 访问首页：页面标题为 CTFHub BackUp Vim，提示 Flag 在 index.php 源码中。
  2. 确定交换文件名：目标文件是 index.php，因此按 Vim 默认命名规则访问隐藏文件： 
    curl.exe -i "http://challenge-xxx.sandbox.ctfhub.com:10800/.index.php.swp"
  3. 确认文件泄露：服务器返回 200 OK 且响应内容以 b0VIM 9.1 开头，说明下载的是有效交换文件。文件中还包含源码路径： 
    /tmp/skill_web_info_leak_backup_vim/src/index.php
  4. 提取源码内容：下载到本地后使用字符串提取命令查看可读内容： 
    curl.exe -sS "http://challenge-xxx.sandbox.ctfhub.com:10800/.index.php.swp" -o index.php.swp
strings index.php.swp
    交换文件中保留了原源码的 PHP 行和 Flag 注释： 
    <?php
// ctfhub{1c9bc0e9de156aea54073b92}
?>
  5. 获取 Flag：从源码注释中提取完整 Flag 并提交。

五、最终 Flag

ctfhub{1c9bc0e9de156aea54073b92}

六、修复建议

  • 禁止 Web 服务器直接访问 .swp、.swo、.swn 等 Vim 临时文件。
  • 部署前检查并清理源码目录中的隐藏文件和编辑器缓存文件。
  • 通过构建流程发布制品，避免将开发目录或源码编辑环境直接部署到线上。

七、解题总结

本题的关键是根据题目提示构造 Vim 默认交换文件名 .index.php.swp。交换文件不属于 PHP 源码，服务器不会解析其中的内容，而是将它作为普通文件下载，从而造成源码信息泄露。
