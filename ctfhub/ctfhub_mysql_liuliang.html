CTFHub - Misc - 流量分析 - MySQL流量

# CTFHub # Misc # 流量分析 # Wireshark

一、题目信息

  • 题目名称：MySQL流量
  • 题目方向：Misc - 流量分析
  • 题目附件：mysql.pcap

二、解题工具

  • Wireshark (网络协议分析器)

三、解题思路与步骤

  1. 下载附件并导入：将题目提供的 mysql.pcap 文件下载到本地，使用 Wireshark 打开。
  2. 过滤流量：因为题目明确是 MySQL 流量，我们在 Wireshark 顶部的显示过滤器栏中输入 mysql 并回车，过滤掉无关的 TCP/HTTP 等流量，只保留 MySQL 协议的数据包。
  3. 追踪 TCP 流：在过滤出的结果中，可以看到客户端向服务器发送了很多 Request Query（请求查询）的数据包。选中任意一个 Request Query 数据包，右键点击 -> 选择 追踪流 (Follow) -> TCP 流 (TCP Stream)。
  4. 分析数据流：在弹出的 TCP 流窗口中，可以清晰地看到客户端与服务器之间的明文交互过程。滚动窗口查找，发现执行了 select * from users 查询语句。
  5. 寻找 Flag：在 select * from users 查询语句下方，紧接着返回了查询结果（Response），在结果中我们看到了明文字符串 ctfhub{mysql_is_S0_E4sy}。

四、最终 Flag

ctfhub{mysql_is_S0_E4sy}

五、解题总结

这道题是一道非常基础的流量分析题，主要考察对于 Wireshark 的基本使用。核心知识点在于：

  • 熟练使用协议过滤器（如 mysql、http、tcp）来缩小排查范围。
  • 掌握“追踪 TCP 流”功能，这能绕过繁琐的数据包拼接，直接查看协议层的明文交互，是流量分析题中找 Flag 的利器。
  • 注意 Flag 的格式（本题为 ctfhub{...}）。
