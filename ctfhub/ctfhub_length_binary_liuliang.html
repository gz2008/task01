CTFHub - Misc - 流量分析 - LengthBinary

# CTFHub # Misc # 流量分析 # Wireshark # ICMP

一、题目信息

  • 题目名称：LengthBinary
  • 题目方向：Misc - 流量分析
  • 题目附件：icmp_len_binary.pcap

二、解题工具

  • Wireshark (网络协议分析器)

三、解题思路与步骤

  1. 导入并过滤：将附件导入 Wireshark。因为题目提示和 ping 包有关，使用 icmp 或 icmp.type==8（仅查看请求包，非常重要，避免请求与回复包造成数据错位）进行过滤。
  2. 观察长度规律：点击 Time 列按时间排序后，观察 Length 列。发现数据包的长度只有两种固定取值：74 和 106。
  3. 映射为二进制：结合题目名称中的 "Binary"（二进制），可以推断这两种长度分别代表 0 和 1。
    • 令较小值 74 = 0，较大值 106 = 1。
    • 提取前 8 个请求包的长度序列：74, 106, 106, 74, 74, 74, 106, 106。
    • 转换为二进制：01100011，转 ASCII 码恰好为 c，验证成功。
  4. 批量转换：按时间顺序提取所有请求包的长度，映射为 0/1 序列。每 8 位二进制数转为一个 ASCII 字符。

四、最终 Flag

ctfhub{04e6fed1e05}

五、解题总结

  • 隐蔽信道：这是一道经典的利用包长度属性进行信息编码的题目。流量分析不仅要注意 Payload 内容，也要关注包的长度、时间间隔等元数据。
  • 区分 Request 与 Reply：在做 ICMP 相关的流量分析时，务必首先区分请求包和回复包（通常只提取其中一种），否则会导致提取的数据序列翻倍或错位，无法得到正确的 ASCII 码。
