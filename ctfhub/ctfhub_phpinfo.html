CTFHub - Web - 信息泄露 - PHPINFO

# CTFHub # Web # 信息泄露 # PHPINFO # 信息收集

一、题目信息

  • 题目名称：PHPINFO
  • 题目方向：Web - 信息泄露
  • 题目环境：动态分配的 HTTP 服务地址
  • 题目目标：根据首页提示访问 PHPINFO 页面，在服务器配置或环境变量中查找 Flag。

二、解题工具

  • 浏览器：查看 PHPINFO 页面并使用页面搜索功能。
  • cURL：获取页面内容并快速筛选关键字。

三、解题思路与步骤

  1. 访问首页：题目首页标题为“phpinfo”，页面中提供了“点击查看phpinfo”按钮，对应的链接为 /phpinfo.php。
  2. 打开 PHPINFO 页面：访问 /phpinfo.php 后，可以看到 PHP 版本、Apache 环境、PHP 配置项、扩展信息和环境变量等大量输出。由于页面内容很多，手工逐项翻看效率较低。
  3. 搜索关键字：在浏览器中按 Ctrl + F，依次搜索 flag 或 ctfhub{，快速定位敏感内容。
  4. 检查环境变量：在 Environment 区域可以找到名为 FLAG 的环境变量；在 PHP Variables 区域则可以看到 $_ENV['FLAG']，两者保存的内容相同。
  5. 使用 cURL 快速获取：也可以直接请求 PHPINFO 页面并筛选包含 Flag 的行： 
    curl.exe -s "http://challenge-xxx.sandbox.ctfhub.com:10800/phpinfo.php" | Select-String -Pattern "FLAG|ctfhub"
    命令会直接显示环境变量中的 Flag。

四、最终 Flag

ctfhub{339e88c80e827350b2db2000}

五、解题总结

  • PHPINFO 属于高敏感信息：它会泄露 PHP 版本、服务器路径、模块配置、HTTP 请求信息以及环境变量，生产环境不应公开访问。
  • 环境变量是重点检查区域：Flag 经常被直接写入 FLAG 环境变量，并同时出现在 Apache Environment、$_SERVER 和 $_ENV 中。
  • 优先使用搜索：PHPINFO 输出非常长，直接搜索 flag、ctfhub{、secret 等关键字比逐项阅读更高效。
  • 信息泄露题的思路：先根据页面提示访问调试接口，再从配置、环境变量和服务器元数据中寻找敏感值。
