task03 Bugku CTF 随机数字运算验证码解题Writeup

题目信息

平台：Bugku CTF

分类：Web入门自动化交互

分值：10分

解题思路

打开挑战页面后会持续刷新随机加减乘运算题，手动输入完全无法满足页面的响应时限，常规人工操作根本不可能通关。核心考点是通过浏览器原生JS实现全自动运算+提交的闭环逻辑，同时要规避eval误解析页面底部BugKu-ctf无关文本的报错坑。

详细步骤

1. 进入题目详情页，按下快捷键 F12 打开浏览器开发者工具，切换到「控制台」标签页

2. 先粘贴清空历史残留定时器的代码，避免后台旧任务报错干扰，按回车执行

3. 再粘贴全自动运算提交脚本，按回车运行，脚本会自动循环执行几十轮运算提交

4. 数秒后页面自动弹出flag，直接复制提交即可通关

完整通关脚本

// 清空所有后台残留的历史定时器
for(let i = 1; i < 9999; i++) clearInterval(i);

// 全自动运算提交脚本
setInterval(() => {
    // 精准定位顶部运算块，完全避开下方无关链接文本
    let qsText = document.querySelector("body").children[0].innerText;
    // 正则提取两个运算数自动转数值
    let numList = qsText.match(/\d+/g);
    let a = +numList[0], b = +numList[1];
    // 提取运算符号
    let op = qsText.match(/[+\-*/]/)[0];
    // 手动分支运算，彻底抛弃eval避免误解析
    let result;
    if(op === '+') result = a + b;
    else if(op === '-') result = a - b;
    else if(op === '*') result = a * b;
    else if(op === '/') result = a / b;
    // 自动填答案点击验证按钮
    let inputs = document.getElementsByTagName("input");
    inputs[0].value = result;
    inputs[1].click();
}, 50);
