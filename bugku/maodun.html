task23 Bugku CTF [矛盾]解题WriteUp

题目信息

平台: Bugku CTF
分类: WEB - PHP 弱类型比较
日期: 9月14日
分值: 10分

解题思路

题目名称为 矛盾，点击“启动场景”后，页面给出了关键的 PHP 源码：

$num=$_GET['num']; if(!is_numeric($num)) { echo $num; if($num==1) echo 'flag{**********}'; }

代码的逻辑是：通过 GET 方式接收参数 num。首先判断 !is_numeric($num)，也就是 $num 不能是数字或纯数字字符串。如果满足条件，则输出 $num，接着判断 $num==1，如果成立则输出 flag。

核心矛盾点：一个值既不能是数字，又要等于数字 1。这利用的是 PHP 的弱类型比较特性。在 PHP 中，当字符串与数字进行 == 比较时，字符串会被强制转换为数字。如果字符串以数字开头，则转换时会截取前面的数字部分。例如字符串 "1abc" 与数字 1 比较时，"1abc" 会被转换为 1，因此 1 == 1 成立。同时，is_numeric("1abc") 会返回 false，因为它不是一个合法的数字字符串。这就完美绕过了两个条件。

详细步骤

  1. 在题目页面点击“启动场景”，获取目标 URL（例如：http://160.202.254.160:15134）。
  2. 在 URL 后面构造 payload，传入参数 num。常用的 payload 有：?num=1abc、?num=1%00 或 ?num=1 or 1=1。
  3. 在浏览器地址栏访问构造好的 URL，例如：http://160.202.254.160:15134/?num=1abc。
  4. 页面会先输出 1abc，随后输出 flag{**********}。
  5. 将输出的 flag 提交到平台即可。

工具及操作说明

# 推荐操作方式（纯浏览器操作，无需脚本）： 1. 启动场景，获取目标 URL 2. 在 URL 地址栏后追加 payload： ?num=1abc 或者 ?num=1%00 3. 回车访问，页面即可回显 flag # 原理说明： - is_numeric("1abc") 返回 false （绕过 !is_numeric） - "1abc" == 1 在 PHP 中为 true （利用弱类型转换，字符串转为数字1） - 同理 "1%00" == 1 也为 true # 拓展：如果是强类型比较（===），此方法无效。

最终Flag

访问构造的 URL 后，页面回显的 flag{...} 即为最终答案
