task21 Bugku CTF [这不是md5]解题WriteUp

题目信息

平台: Bugku CTF
分类: Crypto - Base16（十六进制）编码
日期: 9月11日
分值: 30分

解题思路

题目名称为 这不是md5，描述中给出了一串长度为 32 位的十六进制字符串：666c61677b616537333538376261353662616566357d。

乍一看长度很像 MD5 哈希值（32位），但题目明确提示“这不是md5”，这是典型的误导。观察字符串内容，全部由 0-9 和 a-f 组成，这实际上是 Base16（十六进制）编码。每两个十六进制字符代表一个 ASCII 字符，将其解码为文本即可得到 Flag。

详细步骤

  1. 复制题目描述中给出的十六进制字符串：666c61677b616537333538376261353662616566357d。
  2. 打开 Bugku 在线工具箱，找到 “Base16解码” 或 “Hex解码” 工具。
  3. 将字符串粘贴到输入框中。
  4. 点击“解码”按钮。
  5. 下方输出结果即为 Flag：flag{ae73587ba56baef5}。

工具及操作说明

# 推荐直接使用 Bugku 平台自带在线工具： https://ctf.bugku.com/tool # 操作顺序（无需任何脚本，纯网页点击）： 1. 复制题目描述中的十六进制字符串 2. 在 Bugku 在线工具箱中，选择 "Base16解码" 或 "Hex解码" 3. 粘贴字符串，点击解码 4. 输出结果即为 Flag # 踩坑提示： 不要被 32 位长度和题目名称误导去尝试 MD5 解密。MD5 是不可逆的， 而这道题只是长得像 MD5 的十六进制 ASCII 编码。直接按 Base16 处理即可。
