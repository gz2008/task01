task26 Bugku CTF [备份是个好习惯]解题WriteUp

题目信息

平台: Bugku CTF
分类: WEB - 源码泄露 / 变量覆盖绕过 / PHP 弱类型比较
日期: 9月14日
分值: 20分

解题思路

题目名称为 备份是个好习惯，直接暗示目标网站存在源码备份文件泄露。本题的解题链条为：

  1. 源码泄露：扫描并下载常见的备份文件（如 index.php.bak）。
  2. 代码审计：分析源码发现使用了 str_replace('key','',$str) 对 URL 参数进行过滤，导致直接传参被破坏。
  3. 双写绕过：利用双写构造 kekeyy1、kekeyy2，经过过滤后刚好还原为 key1、key2 变量。
  4. MD5 弱类型碰撞：传入两个 MD5 值均为 0e 开头的不同字符串，满足 == 弱比较但值不相等。

详细步骤

  1. 在题目页面点击“启动场景”，获取目标 URL（如：http://160.202.254.160:16325）。
  2. 尝试访问 http://160.202.254.160:16325/index.php.bak，成功下载到源码文件。
  3. 使用 VS Code 打开 index.php.bak，审计核心源码（截取关键逻辑）：
    <?php include_once "flag.php"; ini_set("display_errors", 0); $str = strstr($_SERVER['REQUEST_URI'], '?'); $str = substr($str,1); $str = str_replace('key','',$str); parse_str($str); echo md5($key1); echo md5($key2); if(md5($key1) == md5($key2) && $key1 !== $key2){ echo $flag."取得flag"; } ?>
  4. 代码审计要点：
    • 第 13 行：str_replace('key','',$str) 会将 URL 参数中的 key 字符串全部替换为空。
    • 第 18 行：需满足 md5($key1) == md5($key2)（弱类型比较）且 $key1 !== $key2（值不全等）。
  5. 构造绕过 Payload：
    • 由于 key 会被过滤，直接传 key1 会变成 1，变量缺失。
    • 使用双写绕过：传入 kekeyy1，中间的 key 被删掉后剩下 key1，成功赋值。
    • 构造 MD5 0e 碰撞：传入 kekeyy1=QNKCDZO 和 kekeyy2=240610708。
  6. 在浏览器地址栏输入最终的 payload：
    http://160.202.254.160:16325/?kekeyy1=QNKCDZO&kekeyy2=240610708
  7. 页面回显 取得flag 和真正的 flag，提交即可。

工具及操作说明

# 1. 下载源码： URL 后加 /index.php.bak 下载源码文件。 推荐使用 VS Code 打开，PHP 语法高亮便于审计。 # 2. 双写绕过原理： str_replace('key', '', 'kekeyy1') 的结果是 'key1' 即：删除了中间的 'key'，剩余 'ke' + 'y1' = 'key1' # 3. MD5 0e 碰撞原理： QNKCDZO -> md5 = 0e830400451993494058024219903391 240610708 -> md5 = 0e462097431906509019562988736854 两者在 == 弱比较时，会被当成 0 == 0 处理（科学计数法）， 但字符串本身严格不全等（!==），完美满足条件。

最终Flag

访问上述 payload 后，页面回显的 flag{...} 即为最终答案
