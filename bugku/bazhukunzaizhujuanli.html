task24 Bugku CTF [把猪困在猪圈里]解题WriteUp

题目信息

平台: Bugku CTF
分类: Crypto - 猪圈密码 / Base64 图片
日期: 9月14日
分值: 15分

解题思路

题目名称为 把猪困在猪圈里，附件内容是一长串以 /9j/ 开头的字符串。这是典型的 Base64 编码的 JPEG 图片（JPEG 图片的 Base64 编码通常以 /9j/4AAQSkZJRg 开头）。结合题目名称中的“猪圈”二字，可以确定这是 猪圈密码（Pigpen Cipher） 的题目。我们需要先将附件解码为图片，然后使用猪圈密码在线工具解密图片中的符号。

详细步骤

  1. 下载附件，打开 file (2).txt，全选复制所有内容。
  2. 打开在线 Base64 转图片工具（如 Base64 Files）。
  3. 将复制的 Base64 字符串粘贴到左侧输入框中。如果工具未自动识别格式，手动选择 PNG - image/png 或 JPEG - image/jpeg。
  4. 点击“预览图片”，工具会生成一张包含几何符号的图片（尺寸约 369×51 px）。将图片保存到本地。
  5. 打开猪圈密码在线解密工具：http://www.hiencode.com/pigpen.html。
  6. 在工具页面中，对照图片上的符号，逐个点击对应的猪圈密码按钮，工具会实时输出对应的明文字母。
  7. 全部符号输入完毕后，得到明文 thisispigpassword，加上 flag{} 格式即为最终 Flag。

工具及操作说明

# 推荐操作方式（纯网页操作，无需脚本）： 1. 复制附件中的 Base64 字符串 2. 访问 https://base64.us/ 粘贴并预览，下载为 .png 图片 3. 打开 http://www.hiencode.com/pigpen.html 4. 对照图片符号，在工具中逐个点击对应的猪圈密码按钮 5. 工具自动输出明文：thisispigpassword 6. 提交 flag{thisispigpassword} # 猪圈密码简述： 猪圈密码（Pigpen Cipher），又称共济会密码，是一种以格子为基础的 图形替换密码。它使用两个井字格（无点/有点）和两个 X 形格 （无点/有点）共 26 个符号来代表英文字母。 # 常见变体注意： 不同网站使用的猪圈密码变体可能略有差异。hiencode.com 的 猪圈密码工具采用的是一种常见的变体，与本题图片符号完美匹配。

最终Flag

flag{thisispigpassword}
