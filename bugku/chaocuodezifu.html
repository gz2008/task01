task27 Bugku CTF [抄错的字符]解题WriteUp

题目信息

平台: Bugku CTF
分类: Crypto - Base64 变形 / 暴力破解
日期: 9月14日
分值: 10分

解题思路

题目描述：老师让小明抄写一段话，结果粗心的小明把部分数字抄成了字母，还因为强迫症把所有字母都换成大写。你能帮小明恢复并解开答案吗：QWIHBLGZZXJSXZNVBZW

密文 QWIHBLGZZXJSXZNVBZW 长度为 20，全是大写字母。结合“数字抄成字母”和“字母全大写”的线索，可以推断原始字符串是 Base64 编码。小明在抄写时：

  • 把数字抄成了形似的大写字母（如 0→O、1→I/L、2→Z、5→S、6→G、8→B 等）。
  • 把所有小写字母强制转成了大写。

因此，我们需要逆向还原：对密文中的每个字符，穷举它可能是的原始字符（大写本身、对应小写、或形似数字），然后进行 Base64 解码，筛选出包含 flag{ 的结果。由于组合数量约 2600 万种，必须用脚本自动爆破。

详细步骤

  1. 在 VS Code 中新建文件 solve.py，粘贴以下 Python 脚本：
    import itertools import base64 cipher = "QWIHBLGZZXJSXZNVBZW" # 每个字符可能的原始字符 options = [] for c in cipher: opts = [c, c.lower()] # 原始可能为大写或小写 # 数字被抄成形似字母的映射 if c == 'Z': opts.append('2') if c == 'I': opts.append('1') if c == 'B': opts.append('8') if c == 'G': opts.append('6') if c == 'S': opts.append('5') if c == 'L': opts.append('1') if c == 'O': opts.append('0') if c == 'E': opts.append('3') if c == 'A': opts.append('4') if c == 'T': opts.append('7') options.append(list(set(opts))) # 遍历所有组合 for combo in itertools.product(*options): s = ''.join(combo) # 补全 Base64 等号（长度 20 是 4 的倍数，无需补） try: decoded = base64.b64decode(s).decode('utf-8') if 'flag{' in decoded: print(f"[+] 找到: {s}") print(f"[+] 解码: {decoded}") break except Exception: pass
  2. 在 VS Code 中打开终端（Terminal），运行：
    python solve.py
  3. 脚本会自动遍历所有可能的大小写和数字替换组合，进行 Base64 解码。稍等片刻即可在终端看到包含 flag{...} 的结果。
  4. 将输出的 flag 提交到 Bugku 平台即可。
