解题思路与过程（排错记录）

本题核心考察 Linux 基础命令，附件 linux.zip 需要多层解压并提取字符串。但在解题前，本地环境搭建遇到了极大的阻碍，特此记录完整的排错过程：

详细步骤

  1. 环境排错与 WSL 搭建：
    初始在 Windows 下使用 WSL 安装 Ubuntu 报错 0x8007019e。尝试开启系统功能时提示权限不足；随后安装 WSL2 内核更新包报错 0x80071772，向导提前退出。
    最终通过进入 设置 -> Windows 更新，点击“全部下载并安装”打满所有系统补丁（包括 .NET Framework 和安全更新），并确保任务管理器中 CPU 虚拟化已开启。重启电脑后，再次打开 Ubuntu，成功进入初始化界面，设置用户名 gzw 及密码，完成 Linux 环境搭建。
  2. 第一层解压（unzip）：
    附件存于 Windows 的 D:\Open Browser下载 目录下。在 Ubuntu 终端中通过 /mnt/d/ 挂载路径进入该目录，并执行第一层解压：
    cd "/mnt/d/Open Browser下载"
    ls
    unzip linux.zip
    解压后得到 linux 文件夹，里面包含一个 1.tar.gz 文件。
  3. 第二层解压（tar.gz）：
    进入解压出的 linux 目录，确认目录下有 1.tar.gz 文件，执行二次解压：
    cd linux
    ls
    tar -zxvf 1.tar.gz
    解压后得到 test 文件夹，里面包含一个名为 flag 的文件。
  4. 提取 Flag：
    进入 test 文件夹（注意文件夹名为 test，切勿打成 text）。尝试查看 flag 文件内容：
    cd test
    cat flag
    由于文件包含特殊字符，直接 cat 会输出一长串乱码。但仔细观察，能在乱码的末尾成功发现目标字符串，或者使用 strings 命令配合过滤：
    strings flag | grep key
