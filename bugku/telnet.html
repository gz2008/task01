task29 Bugku CTF [telnet]解题WriteUp

题目信息

平台: Bugku CTF
分类: MISC - 流量分析 (Telnet)
日期: 9月15日
分值: 10分

解题思路

题目名称为 telnet，提示 flag 格式为 flag{...}。附件解压后得到 networking.pcap 流量包。

解题核心在于 Telnet 协议是明文传输。这意味着所有数据（包括输入的账号、密码和命令）都可以在数据包中直接看到。我们无需下载 Wireshark，直接利用 VS Code 自带的搜索功能即可轻松定位明文 flag。

详细步骤

  1. 下载附件 telnet.zip，解压得到 networking.pcap。
  2. 用 VS Code 直接打开 networking.pcap。文件内会显示大量乱码（如 NUL、ff、BS 等 Telnet 控制字符），但能看到明文的 Login incorrect 等提示，证明流量未加密。
  3. 在 VS Code 中按下快捷键 Ctrl + F，在搜索框中输入 flag{。
  4. 搜索框会自动定位到明文 flag 的位置，直接复制完整的 flag{xxxxxxxxxxxxxxxxxxxxxxxxxxxxx} 字符串。
  5. 将提取出来的 flag 提交到平台即可。

工具及操作说明

# 推荐操作（零下载，使用现有工具）： 1. VS Code 打开 pcap 文件，直接 Ctrl+F 搜 "flag{" （最快） 2. 备用方案（Git Bash / 命令行）： 在文件所在目录右键打开 Git Bash，输入： strings networking.pcap | grep "flag{" 或者使用 Windows 自带命令： findstr /i "flag{" networking.pcap # 原理说明： Telnet 是明文协议，数据包中直接包含用户输入和系统回显。 截图中看到的红色乱码（如 NUL、ff、BS）是 Telnet 控制字符，直接忽略即可。
