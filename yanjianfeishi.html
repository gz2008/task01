解题思路

题目名称为 眼见非实，附件名为 眼见非实.docx。在 CTF 中，Office 文档（.docx、.xlsx、.pptx）的本质是一个 ZIP 压缩包。

核心原理：Word 文档的本质就是 ZIP。微软的 Office 系列文件（.docx、.xlsx、.pptx）在底层使用的是 Open XML 格式，本质上就是一个 ZIP 压缩包。里面打包了排版信息、文字内容（XML）和图片资源。所以只要把 .docx 改成 .zip，解压出来一定是一个包含 word、docProps 等目录的文件夹。

“眼见非实”这个题目名暗示我们，不能被文件表面的 .docx 后缀所迷惑，必须去探究它底层 ZIP 格式中隐藏的内容。

详细步骤

  1. 下载附件 眼见非实.docx。
  2. 右键文件重命名为 眼见非实.zip（系统提示是否修改扩展名，点击“是”）。
  3. 使用 WinRAR 或 7-Zip 解压该 ZIP 文件，得到一个包含 _rels、customXml、docProps、word 等目录的文件夹。
  4. 用 VS Code 打开这个解压出的文件夹。
  5. 按下 Ctrl + Shift + F 进行全局搜索，输入 flag{。
  6. VS Code 会列出所有匹配的文件和行，直接点击定位并复制完整的 flag 内容。
  7. 如果搜索不到，可以进入 word 文件夹查看 document.xml（正文），或进入 word/media/ 查看图片是否存在隐写。

工具及操作说明

# 操作流程（无需下载额外软件）： 1. 将 .docx 后缀改为 .zip 2. 解压 ZIP 文件 3. 用 VS Code 打开解压目录，Ctrl+Shift+F 搜 "flag{" # 备用方案（使用 Git Bash 命令行）： 在文件目录右键打开 Git Bash，依次执行： mv 眼见非实.docx 眼见非实.zip unzip 眼见非实.zip grep -r "flag{" . # grep 命令会直接输出所有包含 flag 的匹配行，极其方便。 # 如何判断文件是否伪装？ 在 Git Bash 中输入 `file 文件名`，查看真实类型。 或者直接用 VS Code 打开文件，若开头看到 "PK" 字符，即为 ZIP 压缩包。
