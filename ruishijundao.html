task10 Bugku CTF 瑞士军刀解题WriteUp

题目信息

平台: Bugku CTF
分类: PWN入门 - 基础命令执行
日期: 9月11日
分值: 10分

解题思路

题目名为“瑞士军刀”，在网络安全领域，“瑞士军刀”通常指代 Netcat (nc) 这个强大的网络工具。题目描述中直接给出了 ls 命令提示，且提供了连接地址 nc 160.202.254.160 14713。本题考察使用 nc 连接远程服务器，并执行基础的 Linux 命令查找 Flag。

遇到难点与解决：由于 Windows 下的 Git Bash 默认没有内置 nc 命令，直接执行会报错 bash: nc: command not found。因此，我们利用已安装的 Python 编写了一个临时的 socket 脚本，模拟 nc 的交互式网络连接功能。

详细步骤

  1. 打开终端（Git Bash），尝试使用 nc 命令连接题目提供的远程地址：
    nc 160.202.254.160 14713
  2. 终端返回 bash: nc: command not found。我们改用 Python 编写替代脚本。
    编写 nc.py 脚本：
    cat << 'EOF' > nc.py import socket s = socket.socket(socket.AF_INET, socket.SOCK_STREAM) s.connect(('160.202.254.160', 14713)) while True: try: cmd = input('$ ') s.sendall((cmd + '\n').encode()) print(s.recv(4096).decode(), end='') except: break EOF
  3. 运行该 Python 脚本：
    python nc.py
  4. 连接成功后，在远程 Shell 中输入 ls 命令列出当前目录下的文件。
  5. 屏幕上列出了 bin、dev、flag、lib、lib32、lib64、pwn1 等文件。注意，这里的文件名是 flag，没有后缀名。
  6. 一开始尝试 cat flag.txt，系统提示 No such file or directory。随后去掉后缀，使用 cat 命令直接读取该文件内容：
    cat flag
  7. 服务器输出最终 Flag，提交即可通关。
