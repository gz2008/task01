task16 Bugku CTF 入门逆向解题WriteUp

题目信息

平台: Bugku CTF
分类: Reverse - 入门逆向
日期: 9月11日
分值: 10分

解题思路与过程（排错记录）

下载附件解压得到 baby.exe。在尝试提取明文字符串时遇到了极大阻力，特此记录完整的排错过程：

详细步骤

  1. 尝试提取字符串（全部失败）：
    在 Git Bash 中使用 strings 提示命令不存在，改用 grep -a 输出乱码；尝试在 CyberChef 中使用 Strings 操作也未能找到完整的 flag{ 字符串。
  2. 发现根本原因：
    通过查阅解题提示和分析，发现此题出题人没有把 Flag 作为连续字符串存放在数据段中，而是将其拆解成了单字符的 mov 汇编指令（形如 mov [ebp-4], 66h）写在了代码段中。因此常规的字符串提取工具无法抓取。
  3. 手工还原 Flag：
    使用 IDA 等反汇编工具打开文件，定位到 _main 函数。可以观察到从高地址到低地址（或按逻辑顺序排列）的一系列十六进制立即数。将它们按顺序提取出来：
    66h 6Ch 61h 67h 7Bh 52h 65h 5Fh 31h 73h 5Fh 53h 30h 5Fh 43h 30h 4Fh 4Ch 7Dh
  4. ASCII 码转换：
    对照 ASCII 码表（或使用在线十六进制转 ASCII 工具）逐个转换：
    66 -> f 6C -> l 61 -> a 67 -> g 7B -> { 52 -> R 65 -> e 5F -> _ 31 -> 1 73 -> s ...以此类推...
  5. 拼接所有字符，最终得到明文的 Flag。

最终Flag

flag{Re_1s_S0_C0OL}
