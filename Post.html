task08 Bugku CTF POST解题WriteUp

题目信息

平台: Bugku CTF
分类: Web入门POST请求考点
分值: 10分

解题思路

这道题是最基础的POST请求考点，服务器不会从URL的GET参数里读取数据，而是等待客户端通过POST请求体提交名为what、值为flag的参数，校验通过之后就会返回最终flag。不需要额外安装工具，直接用浏览器控制台的fetch函数就能快速构造POST请求完成提交。

详细步骤

  1. 点击页面上的「启动场景」打开挑战页面
  2. 按下F12打开开发者工具，切换到「控制台」标签页
  3. 输入构造好的fetch POST请求代码，按回车执行
  4. 服务器校验POST参数通过，直接返回完整flag

控制台执行代码

fetch(window.location.href, { method: 'POST', headers: { 'Content-Type': 'application/x-www-form-urlencoded' }, body: 'what=flag' }).then(res => res.text()).then(console.log)

最终Flag

flag{这里替换成你实际拿到的flag内容}
