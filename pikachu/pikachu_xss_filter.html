Pikachu - XSS 之过滤绕过

分类：Web / XSS / Filter Bypass · 环境：本机 Pikachu 靶场 · 题目路径：Cross-Site Scripting → xss 之过滤

本文只记录本地授权靶场验证，不针对任何外部系统。会话、Cookie、数据库凭据和真实业务数据均已省略。

一、功能观察

用户输入经过一条只针对 script 标签的正则，随后直接输出到 p 标签。

二、漏洞成因与验证思路

黑名单只删除一种标签，而 HTML 还能通过事件属性执行 JavaScript；服务端没有做上下文编码。

message=<img src=x onerror=alert(1)>
submit=submit
响应中保留了完整的 img 标签和 onerror 事件，未出现 HTML 实体编码。

三、影响

攻击者可用任意事件处理器绕过只过滤 script 的规则，在受害者浏览器中执行脚本。

四、修复建议

在 HTML 文本或属性上下文中使用对应编码，富文本使用严格白名单清洗；不要通过黑名单删除标签。

五、复盘

本关的关键不是记住单个字符串，而是确认输入经过的边界：它进入的是 SQL、Shell、文件系统、HTML 还是 URL 处理器。根因确认后，最小验证应聚焦一个可观察结果，再决定是否需要升级利用链。
