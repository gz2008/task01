Pikachu - XSS 之 JavaScript 输出

分类：Web / XSS / JavaScript Context · 环境：本机 Pikachu 靶场 · 题目路径：Cross-Site Scripting → xss 之 js 输出

本文只记录本地授权靶场验证，不针对任何外部系统。会话、Cookie、数据库凭据和真实业务数据均已省略。

一、功能观察

输入被直接嵌入服务端生成的 JavaScript 字符串变量。

二、漏洞成因与验证思路

输出点位于 script 数据中，HTML 实体会被当作普通字符，不能依靠 HTML 编码修复；这里完全没有 JavaScript 上下文转义。

message=';alert(1);//
submit=submit
响应中的字符串闭合和 alert(1) 语句保持原样，已经跳出原字符串字面量。

三、影响

攻击者可以在页面加载时执行任意 JavaScript，影响取决于页面权限和可读取数据。

四、修复建议

避免把用户数据拼入内联脚本；通过 JSON 安全序列化传递数据，并对 JavaScript 字符串上下文做正确转义。

五、复盘

本关的关键不是记住单个字符串，而是确认输入经过的边界：它进入的是 SQL、Shell、文件系统、HTML 还是 URL 处理器。根因确认后，最小验证应聚焦一个可观察结果，再决定是否需要升级利用链。
