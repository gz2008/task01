Pikachu - 文件包含 本地文件包含

分类：Web / File Inclusion / LFI · 环境：本机 Pikachu 靶场 · 题目路径：File Inclusion → File Inclusion(local)

本文只记录本地授权靶场验证，不针对任何外部系统。会话、Cookie、数据库凭据和真实业务数据均已省略。

一、功能观察

页面用下拉框选择球员介绍，实际服务端根据 filename 包含文件。

二、漏洞成因与验证思路

include "include/$filename" 直接拼接用户参数，没有规范化路径或白名单。

filename=../../../../../../Windows/win.ini
submit=submit
响应中出现了 win.ini 的 [fonts] 小节，证明 include 越过了 include 目录。

三、影响

可读取应用和系统文件；若能包含上传文件或日志内容，还可能升级为代码执行。

四、修复建议

使用固定文件映射或白名单；对路径做规范化并确认最终路径位于允许目录。

五、复盘

本关的关键不是记住单个字符串，而是确认输入经过的边界：它进入的是 SQL、Shell、文件系统、HTML 还是 URL 处理器。根因确认后，最小验证应聚焦一个可观察结果，再决定是否需要升级利用链。
