Pikachu - SQL 注入 - 字符型注入

分类：Web / SQL Injection · 环境：本机 Pikachu 靶场 · 题目路径：SQL-Inject → 字符型注入（GET）

一、漏洞成因

$name = $_GET['name'];
$query = "select id,email from member where username='$name'";

参数位于单引号中，测试时需要先闭合原字符串，再用注释截断后半段。

二、验证过程

GET /pikachu/vul/sqli/sqli_str.php?name=%27%20OR%20%271%27%3D%271%27%20%23&submit=x

解码后 payload 为 ' OR '1'='1' #。本地响应返回了 1 到 7 号会员的 uid 和邮箱，证明 WHERE 条件被改写为永真条件。

三、修复建议

使用预处理语句绑定 name，并统一处理错误信息，避免把数据库语法错误直接暴露给用户。
