Pikachu - 不安全的文件下载

分类：Web / Path Traversal / Download · 环境：本机 Pikachu 靶场 · 题目路径：Unsafe File Download → Unsafe Filedownload

本文只记录本地授权靶场验证，不针对任何外部系统。会话、Cookie、数据库凭据和真实业务数据均已省略。

一、功能观察

球员头像链接通过 execdownload.php?filename=... 下载。

二、漏洞成因与验证思路

下载路径由 download/ 与用户输入直接拼接，只检查 file_exists，没有限制最终目录。

GET /pikachu/vul/unsafedownload/execdownload.php
filename=../../../inc/config.inc.php
响应类型为 application/octet-stream，附件名为 config.inc.php，正文包含配置文件源码。

三、影响

可读取配置、源码和其他可访问文件；配置泄露还可能暴露数据库等后端连接信息。

四、修复建议

下载接口使用服务端文件 ID 映射；规范化路径并验证父目录；禁止把用户输入当文件路径。

五、复盘

本关的关键不是记住单个字符串，而是确认输入经过的边界：它进入的是 SQL、Shell、文件系统、HTML 还是 URL 处理器。根因确认后，最小验证应聚焦一个可观察结果，再决定是否需要升级利用链。
