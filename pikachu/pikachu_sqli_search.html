Pikachu - SQL 注入 - 搜索型注入

分类：Web / SQL Injection · 环境：本机 Pikachu 靶场 · 题目路径：SQL-Inject → 搜索型注入

一、漏洞成因

$name = $_GET['name'];
$query = "select username,id,email from member where username like '%$name%'";

输入被放进模糊匹配语句，但没有转义或参数化。测试时要闭合原有的单引号和百分号结构。

二、验证过程

GET /pikachu/vul/sqli/sqli_search.php?name=%27%20OR%201%3D1%20%23&submit=x

payload 为 ' OR 1=1 #。响应列出了 vince、allen、kobe、grady、kevin、lucy、lili 等会员，说明搜索条件已被绕过。

该页面还把原始输入拼回 HTML，源码中另有反射型 XSS 风险；SQL 注入与 XSS 应分别修复。

三、修复建议

使用预处理语句构造 LIKE 条件，并对输出使用上下文相关的 HTML 转义。
