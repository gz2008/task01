Pikachu - SSRF file_get_contents

分类：Web / SSRF / file_get_contents · 环境：本机 Pikachu 靶场 · 题目路径：SSRF → SSRF(file_get_content)

本文只记录本地授权靶场验证，不针对任何外部系统。会话、Cookie、数据库凭据和真实业务数据均已省略。

一、功能观察

页面把 file 参数交给 file_get_contents，并回显读到的字符串。

二、漏洞成因与验证思路

PHP 文件包装器接受任意 URL 或 file 协议，且服务端没有对协议和目标做限制。

file=http://127.0.0.1:18080/ssrf
file=file:///C:/Windows/win.ini
HTTP 测试返回回调标记；file 测试返回 win.ini 的 [fonts] 内容。

三、影响

既可发起内网请求，也可读取本地文件，影响通常比单一 HTTP SSRF 更大。

四、修复建议

限制 file_get_contents 只接受可信 URL；禁用不必要包装器；对远程请求使用安全客户端和地址白名单。

五、复盘

本关的关键不是记住单个字符串，而是确认输入经过的边界：它进入的是 SQL、Shell、文件系统、HTML 还是 URL 处理器。根因确认后，最小验证应聚焦一个可观察结果，再决定是否需要升级利用链。
