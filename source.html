task09 Bugku CTF source解题WriteUp

题目信息

平台: Bugku CTF
分类: Web入门 - Git源码泄露
日期: 9月11日
分值: 10分

解题思路

这道题的名称是 source（源码），考点是 Git 源码泄露。服务器错误地将隐藏的 .git 目录暴露在了公网上，我们可以通过下载该目录中的文件，回溯 Git 的历史提交记录，从而找到被删除或者隐藏的 Flag。

常规的 git clone 命令由于服务器未开启相关协议而报错，因此我们使用了更强大的工具 git-dumper 来完成源码拉取，并使用 git reflog 和 git show 命令来查看被隐藏的提交内容。

详细步骤

  1. 打开题目网页（如 http://160.202.254.160:13273/），页面只显示 Hello, world! 没有任何有效信息。
  2. 猜测并尝试访问隐藏目录：在浏览器中访问 http://160.202.254.160:13273/.git/，发现返回了 403 Forbidden 或目录列表，确认存在 Git 源码泄露。
  3. 打开 Git Bash 命令行工具，尝试使用 git clone 命令下载源码，但提示 fatal: repository ... not found，说明服务器拒绝了标准的 Git 协议请求。
  4. 改用 git-dumper 工具，直接通过 HTTP 协议抓取整个 .git 目录并在本地还原仓库：
    git-dumper http://160.202.254.160:13273/.git/ ./source
  5. 下载成功后，进入源码目录：cd source
  6. 查看 Git 历史操作记录：git reflog，发现一条可疑的提交记录，哈希值为 40c6d51，提交信息为 "commit: flag is here?"。
  7. 查看该具体提交修改了哪些内容：git show 40c6d51，发现它将 flag.txt 文件中的 flag{nonono} 修改为了真正的 Flag。

关键命令

# 1. 使用 git-dumper 拉取源码 git-dumper http://靶场IP:端口/.git/ ./source # 2. 进入目录并查看历史记录 cd source git reflog # 3. 查看哈希为 40c6d51 的提交修改内容 git show 40c6d51
