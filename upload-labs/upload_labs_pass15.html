Upload-Labs Pass-15：getimagesize() 图片马

Upload-Labs Web File Upload getimagesize 图片马

Pass-15 使用 getimagesize() 判断文件能否被识别为图片。这个函数会解析图片头并返回宽高和类型，但不会删除图片后的附加数据。因此合法图片后追加 PHP 探针仍能通过。

验证状态：JPG、PNG、GIF 三种图片马均通过 getimagesize()；使用靶场文件包含页后均执行并返回 IMAGE_INCLUDE_OK。

一、核心代码

$info = getimagesize($tmp_file);
$ext = image_type_to_extension($info[2]);
if (stripos('.jpeg|.png|.gif', $ext) >= 0) {
    $img_path = UPLOAD_PATH."/".rand(10, 99).date("YmdHis").$ext;
    move_uploaded_file($tmp_file, $img_path);
}

函数识别到合法图片后会返回类型，但临时文件内容被原样移动，没有重新编码。

二、复现

使用与 Pass-14 相同的 8×8 图片，在文件末尾追加：

<?php echo "IMAGE_INCLUDE_OK"; ?>

上传时仍使用正确的 multipart MIME 类型。服务端生成的 JPG、PNG、GIF 文件都通过检查。访问图片本身只显示图片内容；通过 include.php 包含后，末尾的 PHP 片段被执行。

格式服务端扩展名包含结果
JPEG.jpegIMAGE_INCLUDE_OK
PNG.pngIMAGE_INCLUDE_OK
GIF.gifIMAGE_INCLUDE_OK

三、与 Pass-14 的区别

Pass-14 只看两个字节，Pass-15 能看到图片尺寸和类型，检查强度更高，但仍只回答“这是不是一张可识别的图片”。它不回答“文件里是否还有额外脚本”，更没有执行图片重新编码。

四、修复建议

  • 使用 getimagesize() 后继续完整解码图片。
  • 用服务端配置的固定格式重新编码，而不是原样保存。
  • 把文件保存到非 Web 根目录，并禁止包含函数读取上传文件。
  • 对图片使用独立域名或无脚本的静态文件服务。

五、复盘

图片校验函数证明的是文件头可解析，不是内容纯净。Pass-15 的完整链路同时依赖“图片可通过校验”和“上传文件能被包含执行”，两者缺一不可。
