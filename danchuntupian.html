task11 Bugku CTF 这是一张单纯的图片解题WriteUp

题目信息

平台: Bugku CTF
分类: MISC - 图片隐写
日期: 9月11日
分值: 10分

解题思路

题目名为“这是一张单纯的图片”，描述给出了提示 key{}。下载图片后直接用记事本搜索 key 找不到明文，说明使用了编码。我们使用记事本打开图片，按 Ctrl+End 跳转到文件末尾，发现了一串 HTML 实体编码（类似 ke...）。

解题技巧：利用浏览器天生支持渲染 HTML 的特性，直接将图片文件的后缀名从 .jpg 修改为 .html，然后用浏览器打开。浏览器会自动将实体编码解析为人类可读的明文，直接获取 Flag。

详细步骤

  1. 下载图片，右键用“记事本”打开。
  2. 按 Ctrl+End 跳到文件最末尾，发现编码：
    key{123_wu are so cute}
  3. 右键图片，选择“重命名”，将后缀 .jpg 改为 .html。
  4. 双击用浏览器打开这个 HTML 文件，浏览器自动将编码解析为：key{123_wu are so cute}。
  5. 复制该字符串并提交。若平台禁止空格，则将空格替换为下划线后提交：key{123_wu_are_so_cute}。

最终Flag

key{123_wu_are_so_cute}
